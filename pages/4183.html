Removal and Installation

Reset the parking and back-up sensor control unit after doing any of the following actions:

  • When you replace the parking and back-up sensor.
  • When you change the parking and back-up sensor mounting location from the original location.
  1. Front Bumper - Remove
  2. Front Corner Sensor - Remove
    Courtesy of HONDA, U.S.A., INC.
    		 1. Disconnect the connector (A).

    2. Remove the front corner sensor (B).

    3. Remove the retainer (C).
  3. All Removed Parts - Install
    1. Install the parts in the reverse order of removal.
