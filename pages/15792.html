Mis-Fuel Inhibit Device Removal and Installation (2016 2017 2018): Installation

WARNING: 

Flammable - Keep Fire Away

NOTE:  Refer to the Fuel and Emissions Systems Service Precautions before disconnecting the fuel line.

  1. Main Flap Unit - Install (If necessary)

    1. Position the new main flap unit (A) onto the filler neck (B) with the top arrow (C) at the 1 o'clock position.

    Courtesy of HONDA, U.S.A., INC.

    2. Install the main flap unit (A) by doing the following:

    • Set the capless wrench onto the main flap unit.
    • While pressing down on the capless wrench, turn the main flap unit counterclockwise until you hear a click. The arrow on the main flap unit should face up.
    • Slightly turn the capless wrench clockwise to confirm that the lock tab is engaged. The main flap unit should not turn.
    Courtesy of HONDA, U.S.A., INC.
