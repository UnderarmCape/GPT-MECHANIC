Send Tech Line Snapshots When Calling For Auto Idle Stop System Issues (A18070D VERSION 2)

WARNING: This page is about the Civic EX-L, 2D Coupe, which is a different variant/trim than selected.
Publication date: 2019-06-01
Reference number: A18070D VERSION 2
Supersedes refnos: A18070D

SEND TECH LINE SNAPSHOTS WHEN CALLING FOR AUTO IDLE STOP SYSTEM ISSUES

SEND TECH LINE SNAPSHOTS WHEN CALLING FOR AUTO IDLE STOP SYSTEM ISSUES

TECHNICAL SERVICE BULLETIN

Reference Number(s): A18070D Version 2, Date of Issue:  June 01, 2019
HONDA: ALL Models

AFFECTED VEHICLES

ALL Models with Auto Idle Stop

EDITOR'S NOTE:  This article replaces the one issued in July 2018. 

Until recently, Tech Line had only two categories for auto idle stop system issues. That made it hard for our engineering staff to understand what was specifically inhibiting the system.

To help with this, Tech Line has added more categories to match what's listed in the service information. As a result, when calling them for an auto idle stop issue, you must now send a snapshot. Tech Line needs it for troubleshooting and won't be able to help unless you do.

Our engineering staff will then use this categorized info to address market issues and ultimately generate system improvements.
