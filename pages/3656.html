DTC C0015-49: Outlet Solenoid (Right Front) Circuit Failure

Confirmation Procedure Basic Condition:
  • 12 volt battery voltage 10 V or more

Operating Condition:

  • Start the engine, then wait for 2 seconds or more.
Execution Initial Diagnosis/Regular Diagnosis
Duration About 2 seconds
DTC Type
  • 1 drive cycle
  • Brake system indicator (red) on
  • Brake system indicator (amber) on
  • ABS indicator on
  • VSA indicator on
Fail Safe Action
  • Stop ABS function
  • Stop EBD function
  • Stop brake assist function
  • Stop TCS function
  • Stop VSA function
  • Stop engine drag torque control function
  • Stop hill start assist function
  • Stop agile handling assist function
  • Stop automatic brake hold function
  • Stop driving support system's brake function
  • Stop emergency brake function
Possible Cause
  • VSA modulator-control unit internal failure
