DTC U0073 (Keyless Access Power Control Unit without CAN gateway)

DTC U0073  : F-CAN Communication Bus Line Error

DTC Description DTC
U0073 F-CAN Communication Bus Line Error  

DTC (Power Control Unit)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTCs with the HDS.

    -3. Wait for at least 6 seconds.

    -4. Check for DTCs with the HDS.

    DTC Description DTC
    U0073 F-CAN Communication Bus Line Error  

    Is DTC U0073 indicated?

    YES 

    Go to DLC Circuit Troubleshooting .

    NO 

    Intermittent failure, the system is OK at this time.
