  2. Engine Undercover - Remove
  3. Drive Belt - Remove
    Courtesy of HONDA, U.S.A., INC.
    		 1. Set a wrench on the drive belt auto-tensioner (A), and slowly turn the wrench in the direction of the arrow, then remove the drive belt (B).
    NOTE:  This is a hydraulic type auto-tensioner, so you must turn the wrench slowly for at least 3 seconds.
  4. All Removed Parts - Install
    1. Install the parts in the reverse order of removal.
