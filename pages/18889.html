AUDIO UNIT DISPLAY GOES BLANK THEN RETURNS TO NORMAL

AUDIO UNIT DISPLAY GOES BLANK THEN RETURNS TO NORMAL

TECHNICAL SERVICE BULLETIN

Reference Number(s): 16-036 Version 3, Date of Issue:  May 27, 2017
HONDA: 2016 Civic
Superceded Bulletin(s): 16-036, Date of Issue:  February 18, 2017
NOTE: Supersedes 16-036, dated February 18, 2017.

AFFECTED VEHICLES

AFFECTED VEHICLES

Year Model Trim VIN Range
2016 Civic EX, EX-T, EX-L, Touring ALL

REVISION SUMMARY

The information under SYMPTOM was updated.

SYMPTOM

The audio unit display goes blank, then returns to normal operation within a second.

POSSIBLE CAUSES

The audio unit display has an internal hardware problem.

CORRECTIVE ACTION

Replace the audio unit display.

REPAIR PROCEDURE

NOTE: This procedure is in an outline form, for more information on how to remove these items, refer to the service information
  • With Navigation: Remove the audio-navigation unit assembly.
  • Without navigation: Remove the audio unit assembly.
  1. Disconnect the connector.
  2. Remove the center display unit.
    NOTE: Mark the old display screen with a marker so you don't confuse it with the new one.
  3. Install the new center display unit in the reverse order of removal and torque the display screen to 3.7 N.m (2.7 lb-ft)  .
  4. Install the audio navigation/audio unit assembly.

END
