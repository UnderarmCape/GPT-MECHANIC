Front Upper Seat Back Bolster Deformed (17-045)

WARNING: This page is about the Civic EX-L, 2D Coupe, which is a different variant/trim than selected.
Publication date: 2017-10-12
Reference number: 17-045

FRONT UPPER SEAT BACK BOLSTER DEFORMED

FRONT UPPER SEAT BACK BOLSTER DEFORMED

TECHNICAL SERVICE BULLETIN

Reference Number(s): 17-045, Date of Issue:  October 12, 2017
HONDA: 2016-2017 Civic; 2017 CR-V

AFFECTED VEHICLES

AFFECTED VEHICLES

Year Model Trim VIN Range
2016-17 Civic ALL except Si and Type R ALL
2017 CR-V ALL ALL

BACKGROUND

The seat pad folds under the frame, causing the seat cover material to collapse.

NOTE: This bulletin should only be completed when there is a customer complaint.

PROBABLE CAUSE

When a driver or front passenger enters the vehicle and rubs against the bolster, the seat foam folds and gets caught inside the seat frame.

CORRECTIVE ACTION

  • Install the new seat side airbag holder to the upper seat back frame.
  • Inspect the seat foam and see if it is repairable (foam returns to the original shape), if it is not repairable, replace it.

WARRANTY CLAIM INFORMATION

NOTE: Due to the large number of replacement part options, a Template ID will not be provided. Please file the claim using the regular claim template.

The normal warranty applies.

INSPECTION PROCEDURE

NOTE: Make sure you have reviewed the SRS Precautions and Procedures in the applicable electronic service manual before doing the REPAIR PROCEDURE.
  1. Disconnect the battery and wait 3 minutes
  2. Remove the affected front seat. Refer to the service information.
  3. Remove the front seat-back cover only so you can reach the affected seat foam area. Refer to the service information.
  4. Check to see if the affected seat foam is repairable by massaging it back into original form.

    Is the seat foam repairable? 

    Yes - You do not have to replace the seat foam. Go to the REPAIR PROCEDURE and do the FRONT SEAT SIDE AIRBAG HOLDER procedure only. 

    No - Replace both seat foam and front seat side airbag holder. Go to the REPAIR PROCEDURE and do both FRONT SEAT SIDE AIRBAG HOLDER  and SEAT FOAM AND SEAT HEATER (IF EQUIPPED) .

REPAIR PROCEDURE

NOTE: Only do the repair that is required, see INSPECTION PROCEDURE .

Front Seat Side Airbag Holder

  1. Remove the two screws holding the front seat side airbag holder, and the nut holding the side seat airbag.
    NOTE:
    • Driver's side seat is shown below, the passenger side is a mirror image.
    • The nut holding the airbag is a must replace part, replace it when installing.
  2. Remove the side airbag.
  3. Remove the front seat side airbag holder.
  4. CR-V only:  Remove the two reinforcing clips.
  5. Install the counter-measure front seat side airbag holder.
    NOTE: The counter-measure part is different according to the model you are working on.
  6. Install all other removed parts in the reverse order.
    NOTE: Do not forget to replace the airbag nut with a new one. Torque it to 6.3 N.m (4.6 lb-ft)

Front Seat Foam and Seat Heater (if equipped)

  1. Replace the seat foam and the seat heater (if equipped). Refer to the service information.
    • Front Seat-Back Cover Removal and Installation 
    • Seat Heater Replacement
