Power Windows Symptom Troubleshooting - Auto reverse power window operation malfunction (2-door) (2016 2017 2018 2019 2020)

NOTE:  Refer to the power windows system description in the construction and function guide.

Incorrect actuation of the power window may occur in the following situations:

  • AUTO UP/AUTO DOWN operation while the vehicle is driving over bad roads.
  • AUTO UP/AUTO DOWN operation while the door is opening or closing.
  1. Problem verification 1

    -1. Start the engine.

    -2. Fully open the door glass using the power window AUTO DOWN switch.

    -3. Fully close the door glass using the power window AUTO UP switch.

    Does the door glass reverse as it is closing, or does the door glass reverse at once, after it has completely closed?

    YES 

    Resetting the power window control unit , then go to step 2.

    NO 

    Intermittent failure, the power window is OK at this time.

  2. Problem verification 2

    -1. Fully open the door glass using the power window AUTO DOWN switch.

    -2. Fully close the door glass using the power window AUTO UP switch.

    Does the door glass reverse as it is closing, or does the door glass reverse at once, after it has completely closed?

    YES 

    Go to step 3.

    NO 

    Troubleshooting is complete.

  3. Power window motor/pulser test:

    Check the power window motor/pulser.

    • Driver's 
    • Passenger's 

    Is the power window motor/pulser OK?

    YES 

    Go to step 4.

    NO 

    Faulty power window motor/pulser; replace the front door regulator .

  4. Door glass/door glass outer weatherstrip/door sash/door regulator check

    -1. Remove the front door panel and plastic cover , then remove the bolts holding the window glass to the regulator.

    -2. Slide the window glass up and down in the run channel by hand and feel for any binding.

    Does the window glass bind as it is moving up and down in the run channel?

    YES 

    Repair or replace any parts necessary, then go to step 5.

    NO 

    Go to resetting the power window control unit , then recheck.

  5. Power window operation check

    -1. Resetting the power window control unit .

    -2. Fully open the door glass using the power window AUTO DOWN switch.

    -3. Fully close the door glass using the power window AUTO UP switch.

    Does the door glass reverse as it is closing, or does the door glass reverse at once, after it has completely closed?

    YES 

    Troubleshooting is not complete; go to step 4 and recheck.

    NO 

    Troubleshooting is complete.
