System Indicator

This system has two indicators on the gauge control module.

Courtesy of HONDA, U.S.A., INC.

NOTE:  For locations of each indicator, refer to gauge control module component location index .

When the system is OK, each indicator comes on for about 2 seconds after turning the vehicle to the ON mode, then it goes off. If parking brake is applied, brake indicator (red) is still ON.
