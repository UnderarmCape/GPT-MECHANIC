Resetting Individual Maintenance Items

  1. Connect the HDS.
  2. Select GAUGES in the BODY ELECTRICAL with the HDS.
  3. Select ADJUSTMENT in the GAUGES with the HDS.
  4. Select MAINTENANCE INFORMATION in the ADJUSTMENT with the HDS.
  5. Select MAINTENANCE MINDER in the MAINTENANCE INFORMATION with the HDS.
  6. Select the individual maintenance item you wish to reset with the HDS.
