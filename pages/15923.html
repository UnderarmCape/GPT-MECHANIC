    Millimeter Wave Radar Subassembly Installation 

    1. Install new clips (A) on the radar bracket (B).

    2. Install the millimeter wave radar subassembly (C) on the clips.

    3. Rotate the three clips clockwise to secure the millimeter wave radar subassembly to the radar bracket.

    4. Measure the distance from D to the radar bracket and E to the radar bracket. Both measured values should be within the range of the standard value.

    Standard:  approximately 44.8 mm (1.764 in) 
    Courtesy of HONDA, U.S.A., INC.

    Millimeter Wave Radar Assembly Installation 

    1. Install the millimeter wave radar assembly (A).

    2. Install the harness clip (B).

    3. Connect the connector (C) while holding the millimeter wave radar assembly.

    NOTE:  Applying excessive force may deform the radar bracket.
