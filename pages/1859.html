Gauges Symptom Troubleshooting - Drive mode does not change (K20C1) (2017 2018 2019 2020 2021)

NOTE:  Confirm the control method of the integrated drive-mode system; the electric power steering system , the adaptive damper system , and the VSA system .

  1. DTC check

    -1. Check for DTCs with the HDS.

    All DTCs

    Are any DTCs indicated?

    YES 

    Go to indicated DTC troubleshooting.

    NO 

    Go to step 2.

  2. Drive mode system check

    -1. Check the parameter(s) below with the HDS.

    When the integrated drive-mode switch (↓) is pressed 

    Signal Threshold Current conditions
    Values Unit Values Unit
    Mode UP Switch ON      
    Mode DOWN Switch OFF      

    When the integrated drive-mode switch (↓) is pressed 

    Signal Threshold Current conditions
    Values Unit Values Unit
    Mode DOWN Switch ON      
    Mode UP Switch OFF      

    Are all data list values correct?

    YES 

    Intermittent failure, the system is OK at this time. Check for loose or poor connections.

    NO 

    Go to step 3.

  3. Open wire check (MODE UP, MODE DOWN lines)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    Gauge control module connector A (32P)
    Integrated drive-mode switch 5P connector

    -3. Check for continuity between test points 1 and 2 respectively.

    Test condition Vehicle OFF (LOCK) mode
    Gauge control module connector A (32P): disconnected
    Integrated drive-mode switch 5P connector: disconnected
    Test point 1 Gauge control module connector A (32P) No. 8 
    Test point 2 Integrated drive-mode switch 5P connector No. 4
    Test point 1 Gauge control module connector A (32P) No. 25 
    Test point 2 Integrated drive-mode switch 5P connector No. 3
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    The MODE UP and MODE DOWN wires are not open. Go to step 4.

    NO 

    Repair an open or high resistance in the wire.

  4. Shorted wire check (MODE UP, MODE DOWN lines)

    -1. Check for continuity between test points 1 and 2 individually.

    Test condition Vehicle OFF (LOCK) mode
    Gauge control module connector A (32P): disconnected
    Integrated drive-mode switch 5P connector: disconnected
    Test point 1 Gauge control module connector A (32P) No. 8 
    Test point 2 Body ground
    Test point 1 Gauge control module connector A (32P) No. 25 
    Test point 2 Body ground

    Is there continuity?

    YES 

    Repair a short to ground in the wire.

    NO 

    The MODE UP and MODE DOWN wires are OK. Go to step 5.

  5. Open wire check (GND line)

    -1. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
    Gauge control module connector A (32P): disconnected
    Integrated drive-mode switch 5P connector: disconnected
    Test point 1 Integrated drive-mode switch 5P connector No. 5
    Test point 2 Body ground
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    The GND wire is OK. Replace the integrated drive-mode switch . If the symptom is still present, replace the gauge control module .

    NO 

    Repair an open or high resistance in the wire.
