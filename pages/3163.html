Removal and Installation

  1. Rear Seat Cushion - Remove 
  2. Rear Seat Cushion Cover - Remove
    Courtesy of HONDA, U.S.A., INC.
    		 1. From the back of the rear seat cushion (A), release the upholstery rings (B), then fold back the rear seat cushion cover.
    Courtesy of HONDA, U.S.A., INC.
    		 2. Pull back the edge of the seat cushion cover (A) all the way around, and release the upholstery rings (B).
  3. All Removed Parts - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the parts in the reverse order of removal.
    NOTE:  Replace all of the upholstery rings (A) fastening the seat cushion cover (B) to the pad wires (C) with new ones using commercially available upholstery ring pliers (D).
