Gr8 Battery Diagnostic Station Update Information (09-060)

WARNING: This page is about the Civic EX-L, 2D Coupe, which is a different variant/trim than selected.
Publication date: 2017-09-02
Reference number: 09-060

GR8 BATTERY DIAGNOSTIC STATION UPDATE INFORMATION

GR8 BATTERY DIAGNOSTIC STATION UPDATE INFORMATION

TECHNICAL SERVICE BULLETIN

Reference Number(s): 09-060, Date of Issue:  September 2, 2017
HONDA: All Models
Superceded Bulletin(s): 09-060, Date of Issue:  March 27, 2013
NOTE: Supersedes 09-060, dated March 27, 2013, see REVISION SUMMARY

REVISION SUMMARY

This service bulletin has been revised extensively. American Honda recommends that you review the entire bulletin.

INTRODUCTION

The software for the GR8 Battery Diagnostic Station is updated periodically to fix software bugs and enhance the tool's functionality. You can now update your GR8 via WiFi. It is extremely important to use the latest GR8 software to ensure that the current battery testing and diagnostic procedures are used.

American Honda policy is to ensure that the GR8 testers are updated promptly. The GR8 software must now be updated within 3 days of receiving notification from an iN message or other Honda communications. If an out-of-date version is used, any battery or alternator replacements will not be covered under warranty. 

GR8 UPDATE REQUIREMENTS

  • GR8 Battery Diagnostic Station - P/N MTRGR811ASTH
  • Internet access via WiFi. Go to WIFI Setup for requirements.

To order the GR8 Diagnostic Station, go to the Honda Tool and Equipment catalog on the iN (select Service  > Service Bay  > Tool and Equipment  > Online Catalog  ), or call 888-424-6857. 

SOFTWARE INFORMATION

The current software version is listed online. Go to the iN (select Service  > Service Bay  > Diagnostic Tools Software Versions  ).

To check the software version on the GR8, select Options  > Info  > Version  on the GR8 main menu.

WARRANTY INFORMATION

None. This service bulletin is for information only.

GR8 UPDPATE INSTRUCTIONS

The update should take 20-30 minutes. Make sure that the update is not interrupted. If the update is interrupted, it could damage the GR8 and require you to send the GR8 to Midtronics for repair. This repair is not covered  by warranty.

NOTE: If you have more than one GR8, repeat the update procedure for each unit.

WIFI SETUP

To update the GR8, it must be connected to the internet via your service department WiFi network. For more information see Honda GR8-1100 AST WiFi/CVGM Module Update and Setup  on the service information under General Publications > Tool Information. 

System Update Prompt

When an update is available via the update server, the user will be prompted with the following screen to download and install the update. Follow the prompts on the screen to proceed with the update.

Manual Update

  1. To manually start the update, select Options. 
  2. Scroll up or down and select Setup. 
  3. Scroll up or down and select Update. 

Download and Installation

The update should take around 20-30 minutes, make sure that the update is not interrupted. If the update is interrupted, it could damage the GR8 and require you to send the GR8 to Midtronics for repair. This repair is not covered by warranty.
NOTE:
  • If you have more than one GR8, repeat the update procedure for each unit.
  • If you have any problems updating the GR8, call Midtronics Customer Service at 866-592-8054.

END
