Keyless Access System Symptom Troubleshooting - The doors will not unlock or lock with the door outer handle touch sensor or lock switch, but will unlock or lock with the keyless remote

NOTE: 

  • Before troubleshooting, make sure the No. A18 (10 A) fuse in the under-hood fuse/relay box is OK.
  • Front passenger's *1 is for 4-door, passenger's *2 is for 2-door.
  1. Keyless access system check 1

    -1. Turn the vehicle to the ON mode.

    Does the system change to ON mode?

    YES 

    Go to step 2.

    NO: Without electric steering lock

    Go to keyless access system symptom troubleshooting "Cannot select ON mode with keyless access and with the keyless remote touching the engine start/stop switch" .

    NO: With electric steering lock

    Go to keyless access system symptom troubleshooting "Cannot select ON mode with keyless access and with the keyless remote touching the engine start/stop switch" .

  2. Keyless access DTC check

    -1. Select KEYLESS ACCESS CONTROL UNIT from the ONE-PUSH START system select menu with the HDS, and enter SELF CHECK.

    One-Push - KEYLESS ACCESS CONTROL UNIT- SELF CHECK

    Check for keyless access control unit DTCs with the HDS.

    DTC Description DTC
       

    Are any DTCs indicated?

    YES 

    Troubleshoot the keyless access control unit DTCs.

    NO 

    Go to step 3.

  3. Keyless access system check 2

    -1. Select KEYLESS ACCESS CONTROL UNIT from the ONE-PUSH START system select menu with the HDS, and enter HISTORY DATA.

    One-Push - KEYLESS ACCESS CONTROL UNIT- HISTORY DATA

    Select HISTORY CLEAR, and back to TEST MODE menu.

    -3. Touch the each door outer handle touch sensors, then check the HISTORY DATA.

    History Data 

    DRIVER DOOR UNLOCK SWITCH (OUTER HANDLE TOUCH SENSOR) OK
    FRONT PASSENGER DOOR UNLOCK SWITCH (OUTER HANDLE TOUCH SENSOR) OK

    Is all the information OK?

    YES 

    Go to step 4.

    NO 

    Go to step 6.

  4. Keyless access system check 3

    -1. Push the each door outer handle lock buttons, then check the HISTORY DATA.

    History Data 

    DRIVER DOOR LOCK SWITCH (OUTER HANDLE TOUCH SENSOR) OK
    FRONT PASSENGER DOOR LOCK SWITCH (OUTER HANDLE TOUCH SENSOR) OK

    Is all the information OK?

    YES 

    Go to step 5.

    NO 

    Go to step 8.

  5. Door lock actuator operation check

    -1. Turn the vehicle to the OFF (LOCK) mode, and close all doors.

    -2. Lock and unlock the doors with the driver's door lock switch, and lock and unlock the doors with the front passenger's *1/passenger's *2 door lock switch.

    Do the door lock actuators work normally?

    YES 

    Go to the body control module input test , and do all power, ground, and communication input tests. If the body control module input tests prove OK, replace the body control module .

    NO 

    Check the B-CAN system DTCs. If not, check the door lock system.

    -2. Disconnect the following connectors.

    Each door outer handle 8P connector

    -3. Measure the voltage between test points 1 and 2 respectively.

    Driver's door

    Driver's door outer handle 8P connector: disconnected

    Courtesy of HONDA, U.S.A., INC.

    YES

  10. Open wire check (GND line)

    -1. Check for continuity between test points 1 and 2 individually.

    Driver's door

    Test point 1 Driver's door outer handle 8P connector No. 8

    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    The GND wires are OK. Go to step 11.

    NO 

    Repair an open or high resistance in the ground wire or poor ground (G501, G505).

  11. Open wire check (VOUT FR DR, VOUT FR AS lines)

    -1. Disconnect the following connector.

    Body control module connector G (32P)

    -2. Check for continuity between test points 1 and 2 respectively.

    Driver's door 

    Test condition Vehicle OFF (LOCK) mode
    Driver's door outer handle 8P connector: disconnected
    Body control module connector G (32P): disconnected
    Test point 1 Body control module connector G (32P) No. 31
    Test point 2 Driver's door outer handle 8P connector No. 4
    Courtesy of HONDA, U.S.A., INC.

    Front passenger's *1/passenger's *2 door 

    Test condition Vehicle OFF (LOCK) mode
    Front passenger's*1/passenger's *2 door outer handle 8P connector: disconnected
    Body control module connector G (32P): disconnected
    Test point 1 Body control module connector G (32P) No. 30
    Test point 2 Front passenger's *1/passenger's *2 door outer handle 8P connector No. 4
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    The VOUT FR DR and VOUT FR AS wires are not open. Go to step 12.

    NO 

    Repair an open or high resistance in the wire.
