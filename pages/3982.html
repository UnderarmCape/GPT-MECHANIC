Wireless Charger System Description - Failsafe Function

Hardware Failsafe Control 

When CPU is reset due to CPU program runaway or 5 V supply voltage decrease, it changes to failsafe.

Software Failsafe Control 

When any of the data from the B-CAN circuit cannot be received within a specified time, or an unusual combination of the data is recognized, the wireless charger moves to the software failsafe. The data that cannot be received is forced to a pre-programmed value.
