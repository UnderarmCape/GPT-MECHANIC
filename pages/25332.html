Power Windows System Description - Components (5-door) (2017 2018 2019 2020 2021)

Power Window Master Switch 

The power window master switch has a built-in B-CAN transceiver and a LIN transceiver. The power window master switch sends signals to the front passenger's power window switch and to the moonroof motor-control unit via the LIN.

Front Passenger's Power Window Switch 

The front passenger's power window switch has a built-in control unit. Control is performed by receiving signals from the power window master switch via the LIN.

Power Window Motors 

The motor includes the pulse sensors that detect the window's position and direction with the motor rotation. The rotating direction (up/down) is detected with the rotating cycles from the 2 pulse sensors and the window position is detected by considering 4 pulses as one rotation pulse.
