DTC U0029-00 (Without LKAS (EPS Control Unit))

DTC U0029-00  : F-CAN Malfunction (Bus-Off)

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • Troubleshoot any PGM-FI system DTCs first .
  • This DTC is stored by communication failure between the F-CAN line and the EPS control unit. When DTC U0029-00 is indicated, the F-CAN line has already returned to normal. Check for loose terminals and poor connections at the connectors. If the connectors are OK, clear the DTC and following this troubleshooting.
DTC Description DTC Freeze Frame
U0029-00 F-CAN Malfunction (Bus-Off)    

DTC (EPS)

  1. Connector check (EPS control unit connector B)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Check for loose terminals and poor connections at the following connector.

    EPS control unit connector B (6P)

    Is the connector OK?

    YES 

    Go to step 2.

    NO 

    Repair loose terminal or poor connection. Then clear the DTC by using the HDS and recheck DTC U0029-00. If DTC U0029-00 is not confirmed, troubleshooting is complete.

  2. EPS control unit communication check

    -1. Turn the vehicle to the OFF (LOCK) mode, then start the engine.

    -2. Check for communication between the EPS control unit and the HDS.

    Is there communication between the EPS control unit and the HDS?

    YES 

    Intermittent failure, the system is OK at this time. If the freeze data/on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the Freeze data/on-board snapshot.

    NO 

    Go to DLC circuit troubleshooting .
