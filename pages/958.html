DTC B1002

DTC B1002  : BCM (Body Control Module) Internal Error (EEPROM Error)

NOTE:  If you are troubleshooting multiple DTCs, be sure to follow the instructions in B-CAN System Diagnosis Test Mode A .

DTC Description DTC
B1002 BCM (Body Control Module) Internal Error (EEPROM Error)  

DTC (Body Control Module)

  1. Problem verification

    -1. Clear the DTCs with the HDS.

    -2. Turn the vehicle to the OFF (LOCK) mode and then the ON mode.

    -3. Wait for at least 6 seconds.

    -4. Check for DTCs with the HDS.

    DTC Description DTC
    B1002 BCM (Body Control Module) Internal Error (EEPROM Error)  

    Is DTC B1002 indicated?

    YES 

    Replace the body control module .

    NO 

    Intermittent failure, the body control module is OK at this time.
