DTC C0051-54 (2017 2018 2019 2020 2021)

DTC C0051-54  : Steering Angle Neutral Position Learning Incomplete

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • This DTC is recorded if VSA sensor neutral position memorization is not completed.
  • This DTC is automatically deleted without using the HDS when VSA sensor neutral position memorization is successfully completed.
  • The functions of the integrated driver support system that will be temporarily canceled when this DTC is recorded can be confirmed with the DTC troubleshooting index .
DTC Description DTC
C0051-54 Steering Angle Neutral Position Learning Incomplete  

DTC (IDAS)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    -3. Turn the vehicle to the OFF (LOCK).

    -4. Turn the vehicle to the ON mode, then wait for at least 6 seconds.

    -5. Check for DTCs with the HDS.

    DTC Description DTC
    C0051-54 Steering Angle Neutral Position Learning Incomplete  

    Is DTC C0051-54 indicated?

    YES 

    The failure is duplicated. Perform the VSA sensor neutral position memorization .

    NO 

    Intermittent failure, the system is OK at this time. Refer to intermittent failures troubleshooting .
