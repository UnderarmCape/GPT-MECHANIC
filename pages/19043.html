CPX-900 BATTERY TESTER UPDATE INFORMATION

CPX-900 BATTERY TESTER UPDATE INFORMATION

TECHNICAL SERVICE BULLETIN

Reference Number(s): 22-059, Date of Issue:  December 15, 2022
HONDA: All Models

INTRODUCTION

The software for the CPX-900 Battery Tester is updated periodically to fix software bugs and enhance the tool's functionality. You can download software for your CPX-900 using WiFi and the Internet. It is extremely important to use the latest CPX-900 software to ensure that the current battery testing procedures are used.

The CPX-900 software must be updated promptly after receiving notification from an iN message or other Honda communication. If an out-of-date version is used, battery replacements will not be covered under warranty. 

CPX-900 UPDATE REQUIREMENTS

  • CPX-900 Version 3: P/N MTRCPX900PBARH
  • Internet access via WiFi (Go to WIFI SETUP for requirements).

To order the CPX-900 Battery and Electrical System Analyzer; go to the Honda Tool and Equipment program catalog on the iN (select Service > Service Bay > Tool and Equipment Program > Online Catalog)  , or call 888-424-6857. 

SOFTWARE VERSION

The current software version is listed online. Go to the iN (Service > Service Bay > Diagnostic Tools Software Versions). 

To check the software version on the CPX-900, select Version.  Refer to the number listed as CONFIG. 

WARRANTY CLAIM INFORMATION

None. This service bulletin is for information only.

CUSTOMER INFORMATION:  The information in this bulletin is intended for use only by skilled technicians who have the proper tools, equipment, and training to correctly and safely maintain your vehicle. These procedures should not be attempted by "do-it-yourselfers," and you should not assume this bulletin applies to your vehicle, or that your vehicle has the condition described. To determine whether this information applies, contact an authorized Honda automobile dealer.

CPX-900 UPDATE INSTRUCTIONS

WIFI Setup

To update the CPX-900, it must be connected to the internet via your service department's WiFi network. WIFI settings can be found in SETTINGS>NETWORK>WIFI  and select AUTOMATIC  to start scanning.

For more information see https://hondacpx900.midtronics.com/ 

System Update Prompt

When an update is available via the update server, the user will be prompted with the following screen to download and install the update. Follow the prompts on the screen to proceed with the update.

  1. To start the update, select Messages.
  2. Make sure the device is docked or connected to a good battery and select OK. 
  3. The CPX-900 will commence erasing and then downloading the new software.

Overnight Update

The CPX-900 will update automatically overnight when docked and within WiFi range.

DOWNLOAD AND INSTALLATION

DO NOT disconnect or shut off the power during the update, as this could cause damage to the unit. The download/update progress will be displayed on the screen of the unit.

Confirm the software version by selecting VERSION  and confirm it matches the iN message for the software release.

You can also confirm the software version on the iN; go to Service > Service Bay > Diagnostic Tools Software Versions. 

NOTE:
  • If you have more than one CPX-900, repeat the update procedure for each unit.
  • If you have any problems updating the CPX-900, call Midtronics Customer Service at 866-592-8054.

END
