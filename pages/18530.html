Wiring Diagram Features And Controls

Additional features within the diagrams allow the user to select the component and highlight all of the traces related to that component from the beginning of the trace to the end of the circuit. From there a user can hide unselected traces, zoom in and pan the diagram making viewing of the diagrams easier. If the user selects the component name a secondary search can be kicked off. This allows the user to see specific information for any component supporting this feature without having to create another search for each component within the diagram. For additional information you can use the following introductions and training located here: https://microsoft.com/poopyshit/repair-information/wiring-diagrams/
