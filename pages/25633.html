Wiper Blade Removal and Installation: Installation

Windshield 

  1. Windshield Wiper Blade - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. If necessary, install the end cap (A).
    Courtesy of HONDA, U.S.A., INC.
    		 2. Find the end of the blade holder labeled "SET" (A), and install the wiper starting with the tip that has no projection.

    NOTE:  The wiper end with the projection should not be installed first.

    3. Install the new windshield wiper blade (B).
    Courtesy of HONDA, U.S.A., INC.
    		 4. Install the windshield wiper blade assembly (A) on the windshield wiper arm (B).
