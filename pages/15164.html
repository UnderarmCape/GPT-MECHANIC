DTC P2073 (K20C2)

DTC P2073  : MAP Sensor Signal Higher Than Expected

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • Before you begin, check for poor connections or a blockage at the intake air duct.
DTC Description Confirmed DTC Pending DTC
P2073 MAP Sensor Signal Higher Than Expected    

DTC (PGM-FI)

  1. Vacuum leak check:

    Check for vacuum leaks in these parts:

    • PCV valve
    • PCV hose
    • EVAP canister purge valve
    • Throttle body
    • Intake manifold
    • Brake booster
    • Brake booster hose

    Are there any vacuum leaks?

    YES 

    Repair or replace the parts with vacuum leaks.

    NO 

    Go to step 2.

  2. MAP sensor performance check

    -1. Start the engine.

    -2. Hold the engine speed at 3, 000 rpm without load (CVT in P or N, M/T in neutral) until the radiator fan comes on, then let it idle.

    -3. Check the parameter (s) below with the HDS for 5 seconds.

    Signal Threshold Current conditions
    Values Unit Values Unit
    MAP SENSOR More than 53.3 kPa    
    More than 400.0 mmHg

    Did the value maintain the malfunction threshold for 5 seconds or more?

    YES 

    Replace the MAP sensor .

    NO 

    Go to step 3.

  3. Problem verification

    -1. Clear the DTC with the HDS.

    Test-drive the vehicle under these conditions:

    • Engine coolant temperature (ECT SENSOR 1) above 158 deg.F (70 deg.C)
    • Engine speed between 1, 200-6, 600 rpm
    • CVT in D, M/T in 4th or 5th
    • Drive at a steady speed between 55-75 mph (90-120 km/h) for 10 seconds, then decelerate (with the throttle fully closed) for 2 seconds or more
    Signal Current conditions
    Values Unit
    ECT SENSOR 1    
    ENGINE SPEED    
    VEHICLE SPEED    

    -3. Monitor the OBD STATUS for DTC P2073 in the DTCs MENU with the HDS.

    DTC Description OBD STATUS
    P2073 MAP Sensor Signal Higher Than Expected  

    Does the HDS indicate FAILED?

    YES 

    The failure is duplicated. Replace the MAP sensor .

    NO 

    If the HDS indicates PASSED, intermittent failure, the system is OK at this time. Check for poor connections or loose terminals at the MAP sensor and the PCM. If the on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the on-board snapshot . If the HDS indicates NOT COMPLETED, go to step 3-2 and recheck.
