DTC P2DE0

DTC P2DE0  : Cold Start Air Fuel Ratio Control System Lean

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • If DTC P2DE0 is indicated alone, do the troubleshooting for DTC P0171 using the on-board snapshot for P2DE0.
DTC Description Confirmed DTC Pending DTC
P2DE0 Cold Start Air Fuel Ratio Control System Lean    

DTC (PGM-FI)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Let the engine cool until the value of ECT SENSOR 1 is 122°F (50°C) or less.

    Signal Current conditions
    Values Unit
    ECT SENSOR 1    

    -3. Clear the DTC with the HDS.

    Clear DTC

    -4. Turn the vehicle to the OFF (LOCK) mode.

    -5. Start the engine, and let it idle for 10 seconds or more.

    -6. Check for Pending or Confirmed DTCs with the HDS.

    DTC Description Confirmed DTC Pending DTC
    P2DE0 Cold Start Air Fuel Ratio Control System Lean    

    Is DTC P2DE0 indicated?

    YES 

    The failure is duplicated. Do the troubleshooting for DTC P0171 using the on-board snapshot for P2DE0.

    NO 

    Intermittent failure, the system is OK at this time. If the on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the on-board snapshot .
