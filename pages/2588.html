Power Windows System Description - Control/Function (5-door) (2017 2018 2019 2020 2021)

Basic Control/Function 

  • Manual Up/Down Function

    The 1-step operation of the power window switch moves the window up or down. This is available when the vehicle is in the ON mode or OFF mode (For about 10 minutes after the vehicle is turned to the OFF (LOCK) mode).

  • Auto Up/Down Function

    The 2-step operation of the power window switch moves the window up or down. This is available when the vehicle is in the ON mode or OFF mode (For about 10 minutes after the vehicle is turned to the OFF (LOCK) mode).

Auto Reverse Power Window Function 

When an object is detected during the auto up operation, the window stops closing and reverses about 70 mm (2.76 in). If the window is less than halfway opened (about 220 mm (8.66 in)), it will reverse to the half open position (about 220 mm (8.66 in)). In manual operation, this function is active only during the vehicle OFF operation. This function is activated based on the calculation of the rotation speed and load change of the motor's pulse A.

Courtesy of HONDA, U.S.A., INC.

Vehicle OFF Operation 

For about 10 minutes after the vehicle is turned to the OFF (LOCK) mode, the window's open/close operation with the power window switches is available.

Courtesy of HONDA, U.S.A., INC.
Vehicle OFF Operation Start Condition
  • Vehicle ON mode -> OFF (LOCK) mode
  • Driver's door switch OFF (Door close)
  • Front Passenger's door switch OFF (Door close)
Vehicle OFF Operation Cancel Condition Timer Vehicle ON mode -> OFF (LOCK) mode and past 10 minutes
Door
  • Driver's door switch ON (Door open)
  • Front Passenger's door switch ON (Door open)

Keyless/Key Cylinder Operation 

By turning the key a second time and holding it with the key inserted into the driver's door key cylinder, the windows and moonroof close (or open) (turning the key clockwise to open, turning the key counterclockwise to close). The windows and moonroof stop moving when the key is returned to the neutral position.

By pressing and holding the UNLOCK button of the remote a second time, the windows and moonroof open. The windows and moonroof stop moving when the UNLOCK button is released. The windows do not close with the LOCK button.

Courtesy of HONDA, U.S.A., INC.
