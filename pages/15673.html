DTC U3003-17, U3006-17 (Type-R (Adaptive Damper Control Unit)) (2017 2018 2019 2020 2021)

DTC U3003-17  : Adaptive Damper Control Unit +B Voltage High Failure

DTC U3006-17  : Adaptive Damper Control Unit IG (+B) Voltage High Failure

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • This DTC detected when connecting the high voltage battery (24 V) to the vehicle.
  • Troubleshoot any PGM-FI system DTCs first .
DTC Description DTC Freeze Frame
U3003-17 Adaptive Damper Control Unit +B Voltage High Failure    
U3006-17 Adaptive Damper Control Unit IG (+B) Voltage High Failure    

DTC (Adaptive Damper System)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    Clear DTCs

    -3. Turn the vehicle to the OFF (LOCK) mode, then to the ON mode.

    -4. Wait for 30 seconds or more.

    -5. Check for DTCs with the HDS.

    DTC Description DTC Freeze Frame
    U3003-17 Adaptive Damper Control Unit +B Voltage High Failure    
    U3006-17 Adaptive Damper Control Unit IG (+B) Voltage High Failure    

    Is DTC U3003-17 and/or U3006-17 indicated?

    YES 

    Check for loose terminals and poor connections in the adaptive damper control unit 24P connector. Check for any authorized service information related to the DTCs or symptoms you are troubleshooting. If they are OK, replace the adaptive damper control unit .

    NO 

    Intermittent failure, the system is OK at this time. Refer to intermittent failures troubleshooting . If the freeze data/on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the freeze data/on-board snapshot.
