DTC P0720-62 (2/4-door) (2016 2017 2018)

DTC P0720-62  : Vehicle Speed Signal Error

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • If DTC U0100-00 or DTC U0101-00 is stored at the same time as DTC P0720-62, troubleshoot DTC U0100-00 or DTC U0101-00 first, then recheck for DTC P0720-62.
DTC Description DTC Freeze Frame
P0720-62 Vehicle Speed Signal Error    

DTC (IDAS)

  1. CVT system DTC check

    -1. Turn the vehicle to the ON mode.

    -2. Check for DTCs with the HDS.

    DTC Description Confirmed DTC Pending DTC Freeze Frame
           

    Are any DTCs indicated?

    YES 

    Go to the indicated DTC's troubleshooting .

    NO 

    Go to step 2.

  2. VSA system DTC check

    -1. Check for DTCs with the HDS.

    DTC Description DTC Freeze Frame
         

    Are any DTCs indicated?

    YES 

    Go to the indicated DTC's troubleshooting .

    NO 

    Go to step 3.

  3. Problem verification

    -1. Clear the DTC with the HDS.

    -2. Turn the vehicle to the OFF (LOCK) mode.

    -3. Test-drive the vehicle at 25 mph (40 km/h) or more with the ACC activated, and check the parameter(s) below with the HDS.

    NOTE:  Drive the vehicle on the road, not on a lift.

    Signal Current conditions
    Values Unit
    Vehicle speed    

    Does HDS correspond to the vehicle speed indicated in the gauge control module?

    YES 

    Intermittent failure, the system is OK at this time. Refer to intermittent failures troubleshooting . If the freeze data/on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the freeze data/on-board snapshot.

    NO 

    The failure is duplicated. Go to step 4.

  4. CVT system parameter check

    -1. Test-drive the vehicle at speeds 25 mph (40 km/h) or more with the ACC activated, and check the parameter(s) below with the HDS.

    NOTE:  Drive the vehicle on the road, not on a lift.

    Signal Current conditions
    Values Unit
    Vehicle Speed    

    Does HDS correspond to the vehicle speed indicated in the gauge control module?

    YES 

    Check for loose terminals and poor connections in the multipurpose camera unit 20P connector. Check for any authorized service information related to the DTCs or symptoms you are troubleshooting. If they are OK, replace the multipurpose camera unit .

    NO 

    Go to the CVT system troubleshooting .
