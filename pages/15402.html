Detailed information, notes, and precautions
Replace
*1 Double cone synchro assembly
  1. Angular Ball Bearing - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Press in a angular ball bearing (A) using the 30 mm I.D. driver and a press (B).
    NOTE:  Check the ball bearing install direction.
  2. Needle Bearing - Install
  3. 3rd Gear - Install
  4. Inner Ring - Install
  5. Synchro Cone - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the synchro cone (A) by aligning the synchro cone fingers (B) with the holes (C) in the 3rd gear.
  6. Synchro Ring - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the synchro ring (A) by aligning the synchro ring fingers (B) with the grooves (C).
  7. Synchro Spring - Install
  8. 3rd/4th Synchro Hub - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the 3rd/4th synchro hub (A) by aligning the synchro ring fingers (B) with the grooves (C) in the 3rd/4th synchro hub.
    NOTE:  Make sure to install the 3rd/4th synchro hub in the direction shown.
    Courtesy of HONDA, U.S.A., INC.
    		 2. Press on the 3rd/4th synchro hub (A) using the 40 mm I.D. driver handle and a press (B).
  9. 3rd/4th Synchro Sleeve - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the 3rd/4th synchro sleeve (A) by aligning the stops (B) of the 3rd/4th synchro sleeve and the 3rd/4th synchro hub.

    2. Check the operation of the 3rd/4th synchro hub set .
  10. Synchro Spring - Install
  11. Synchro Ring - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the synchro ring (A) by aligning the synchro ring fingers (B) with the grooves (C) in 3rd/4th synchro hub.
  12. Synchro Cone - Install
  13. Inner Ring - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the inner ring (A) by aligning the synchro ring fingers (B) with the grooves (C) in the inner ring.
  14. 4th Gear - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install 4th gear (A) by aligning the synchro cone fingers (B) with the holes (C) in 4th gear.
  15. Needle Bearing - Install
  16. 4th/5th Gear Distance Collar - Install
  17. Needle Bearing - Install
  18. 5th Gear - Install
  19. Synchro Ring - Install
  20. Synchro Spring - Install
  21. 5th/6th Synchro Hub - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the 5th/6th synchro hub (A) by aligning the synchro ring fingers (B) with the grooves (C) in the 5th/6th synchro hub.
    NOTE:  Make sure to install the 5th/6th synchro hub in the direction shown.
    Courtesy of HONDA, U.S.A., INC.
    		 2. Press on the 5th/6th synchro hub (A) using the 40 mm I.D. driver handle and a press (B).
  22. 5th/6th Synchro Sleeve - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the 5th/6th synchro sleeve (A) by aligning the slots of the 5th/6th synchro sleeve and the 5th/6th synchro hub (B).

    NOTE:  Make sure to align the slots in the 5th/6th synchro sleeve as shown.

    2. Check the operation of the 5th/6th synchro hub set .
  23. Synchro Spring - Install
  24. Synchro Ring - Install
    Courtesy of HONDA, U.S.A., INC.

  26. Needle Bearing - Install
