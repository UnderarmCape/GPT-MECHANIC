DTC B1281, B1282, B1283, B1284

DTC B1281  : Front Wiper MIST Position Circuit Malfunction

DTC B1282  : Front Wiper INT (AUTO) Position Circuit Malfunction

DTC B1283  : Front Wiper LOW Position Circuit Malfunction

DTC B1284  : Front Wiper HIGH Position Circuit Malfunction

NOTE:  If you are troubleshooting multiple DTCs, be sure to follow the instructions in B-CAN System Diagnosis Test Mode A .

DTC (Body Control Module)

  1. Wiper/washers system check

    -1. Turn the windshield wiper switch to the OFF position, check the parameter(s) below with the HDS.

    Signal Threshold Current conditions
    Values Unit Values Unit
    Windshield Wiper Switch (LOW) OFF      
    Windshield Wiper Switch (HIGH) OFF      
    Windshield Wiper Switch (INT) OFF      
    Windshield Wiper Switch (MIST) OFF      

    Are all data list values correct?

    YES 

    Go to step 4.

    NO 

    Go to step 2.

  2. Determine possible failure area (windshield wiper/washer switch, others)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connector.

    Windshield wiper/washer switch 10P connector

    -3. Check the parameter(s) below with the HDS.

    Signal Threshold Current conditions
    Values Unit Values Unit
    Windshield Wiper Switch (LOW) OFF      
    Windshield Wiper Switch (HIGH) OFF      
    Windshield Wiper Switch (INT) OFF      
    Windshield Wiper Switch (MIST) OFF      

    Has the data list value changed from ON to OFF?

    YES 

    Replace the windshield wiper/washer switch .

    NO 

    Go to step 3.

  3. Shorted wire check (FR WIPER INT SW, FR WIPER HI SW, FR WIPER MIST SW lines)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connector.

    Body control module connector D (40P)

    -3. Check for continuity between test points 1 and 2 individually.

    Test condition Vehicle OFF (LOCK) mode
    Windshield wiper/washer switch 10P connector: disconnected
    Body control module connector D (40P): disconnected
    Test point 1 Body control module connector D (40P) No. 2
    Test point 2 Body ground
    Test point 1 Body control module connector D (40P) No. 3
    Test point 2 Body ground
    Test point 1 Body control module connector D (40P) No. 4
    Test point 2 Body ground

    Is there continuity?

    YES 

    Repair a short to ground in the wire.

    NO 

    The FR WIPER INT SW, FR WIPER HI SW, and FR WIPER MIST SW wires are OK. Replace the body control module .

  4. Shorted wire check (FR WIPER MIST SW to FR WIPER HI SW, FR WIPER HI SW to FR WIPER INT SW, FR WIPER MIST SW to FR WIPER INT SW lines)

    -1. Check the parameter(s) below with the HDS.

    When the windshield wiper switch is turned to HI 

    Signal Threshold Current conditions
    Values Unit Values Unit
    Windshield Wiper Switch (LOW) OFF      
    Windshield Wiper Switch (HIGH) ON      
    Windshield Wiper Switch (INT) OFF      
    Windshield Wiper Switch (MIST) OFF      

    When the windshield wiper switch is turned to LO 

    Signal Threshold Current conditions
    Values Unit Values Unit
    Windshield Wiper Switch (LOW) ON      
    Windshield Wiper Switch (HIGH) OFF      
    Windshield Wiper Switch (INT) ON      
    Windshield Wiper Switch (MIST) OFF      

    When the windshield wiper switch is turned to INT (AUTO) 

    Signal Threshold Current conditions
    Values Unit Values Unit
    Windshield Wiper Switch (LOW) OFF      
    Windshield Wiper Switch (HIGH) OFF      
    Windshield Wiper Switch (INT) ON      
    Windshield Wiper Switch (MIST) OFF      

    When the windshield wiper switch is turned OFF 

    Signal Threshold Current conditions
    Values Unit Values Unit
    Windshield Wiper Switch (LOW) OFF      
    Windshield Wiper Switch (HIGH) OFF      
    Windshield Wiper Switch (INT) OFF      
    Windshield Wiper Switch (MIST) OFF      

    When the windshield wiper switch is turned to MIST 

    Signal Threshold Current conditions
    Values Unit Values Unit
    Windshield Wiper Switch (LOW) OFF      
    Windshield Wiper Switch (HIGH) OFF      
    Windshield Wiper Switch (INT) OFF      
    Windshield Wiper Switch (MIST) ON      

    Are all data list values correct?

    YES 

    The FR WIPER MIST SW to FR WIPER HI SW, FR WIPER HI SW to FR WIPER INT SW, and FR WIPER MIST SW to FR WIPER INT SW wires are OK. Intermittent failure, the system is OK at this time. Check for loose or poor connections.

    NO 

    Repair a short between the wires.
