WIRE HARNESS IDENTIFICATION

WIRE HARNESS IDENTIFICATION

TECHNICAL SERVICE BULLETIN

Reference Number(s): AJA11112 Version 2, Date of Issue:  February 25, 2019
HONDA: All Models

APPLIES TO

Models with EWD

INTRODUCTION

If you are having a hard time identifying which wiring harness you are working on, or you want to make sure you are ordering the correct one the first time, here are some tips and a cross reference guide that can help you.

Using the specific EWD for the vehicle you are working on, look for Component Locations  .

For example, if you need to know which harness SRS unit connector B (57P) belongs to, you can find it by searching for the component or connector, or by selecting the component location.

Component or Connector Search 

  • Select Search  in the left window pane, then enter the component and/or connector you are looking for.

Component Location 

  • In the Component Locations  menu in the left window pane, select the component itself or the connector based on its location.

In either case, selecting the link will display the layout of the harness, connectors, and components, as well as a list of connectors and components in the right window pane.

After identifying that you are working with the Floor Wire Harness,  you can use the following cross reference table to provide additional information to your parts department and correctly identify the harness you need. The description should be straightforward in this example, but you can double check by referencing the first five digits of the part number 32107.
