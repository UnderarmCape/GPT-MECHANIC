    Courtesy of HONDA, U.S.A., INC.

    NOTE: 
    • Make sure to align the slots in the 1st/2nd synchro hub as shown.

  13. Inner Ring - Install

  15. Needle Bearing - Install
  16. 2nd Gear - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install 2nd gear (A) by aligning the synchro cone fingers (B) with the holes in 2nd gear (C).
  17. 3rd Gear - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Support the countershaft (A) on steel blocks, then press on 3rd gear (B) using the 58 x 62 mm driver and a press (C).
    NOTE:  Do not exceed the maximum pressure.
  18. 4th Gear - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Press on 4th gear (A) using the 58 x 62 mm driver and a press (B).
    NOTE:  Do not exceed the maximum pressure.
  19. 5th Gear - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Press on 5th gear (A) using the 40 mm I.D. driver handle and a press (B).
    NOTE:  Do not exceed the maximum pressure.
  20. 6th Gear - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Press on 6th gear (A) using the 40 mm I.D. driver handle and a press (B).
    NOTE:  Do not exceed the maximum pressure.
  21. 35 mm Shim - Clearance Check
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the 35 mm shim (A), and temporarily press on the used ball bearing (B) until it bottoms in the direction shown using the 40 mm I.D. driver handle, the 30 mm I.D. bearing driver attachment, and a press (C).
    NOTE:  Use any size of 35 mm shim, and note size you used. Measurements taken in the following steps will determine the correct shim to use for final assembly.
    Courtesy of HONDA, U.S.A., INC.
    		 2. Measure the clearance between the ball bearing (A) and the 35 mm shim (B) with a feeler gauge (C).
    Standard:  0.04-0.10 mm (0.002-0.003 in) 
    • If the measured clearance is not within the standard, select another suitable 35 mm shim from the table, then go to next step to replace the 35 mm shim and the ball bearing with new ones.
    • If the measured clearance is within the standard, go to the next step to replace only the ball bearing with a new one.

  22. 35 mm Shim - Install
  23. Ball Bearing - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the ball bearing (A) until it bottoms in the direction shown using the 40 mm I.D. driver handle, the 30 mm I.D. bearing driver attachment, and a press (B).

    NOTE:  If necessary, replace the 35 mm shim with the correct one selected in step 21-2 (35 mm Shim - Clearance Check).

    2. Recheck the clearance between the ball bearing and the 35 mm shim with a feeler gauge.
  24. Special Bolt - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Securely clamp the countershaft assembly in a bench vise with wood blocks (A).

    2. Tighten a special bolt (B).
