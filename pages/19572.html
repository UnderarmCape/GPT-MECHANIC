Adaptive Damper System Description - System Diagram (Type-R) (2017 2018 2019 2020 2021)

The adaptive damper system controller uses information from the PCM, the VSA modulator-control unit, the EPS control unit, and the SRS unit.

When a malfunction is detected, the multi-information display (MID) will show a warning to inform the driver about the malfunction in the system.

For locations of each component on the vehicle, refer to Component Location Index:

  • Adaptive damper control unit, Adaptive damper unit, Acceleration sensor, Suspension stroke sensor 
  • PCM
  • VSA modulator-control unit
  • Gauge control module
  • EPS control unit
  • SRS unit
