EPS Control Unit Connector A (2P) 

Courtesy of HONDA, U.S.A., INC.
Terminal number Terminal sign Description
1 GND Ground for the EPS control unit
2 +B EPS Power source for the actuator EPS motor

EPS Control Unit Connector B (6P) 

Courtesy of HONDA, U.S.A., INC.
Terminal number Terminal sign Description
1 F-CAN_L *1F-CAN B_L *2 F-CAN communication circuit
2 Not used ---
3 F-CAN_H *1F-CAN B_H *2 F-CAN communication circuit
4 Not used ---
5 IG1 VSA/ABS Power source for activating the system
6 Not used ---

*1: Without LKAS

*2: With LKAS

EPS Control Unit Connector C (4P) 

Courtesy of HONDA, U.S.A., INC.
Terminal number Terminal sign Description
1 T/S GND Ground for the torque sensor
2 T/S VDD Power source for torque sensor
3 TSM Detects torque sensor main signal
4 TSS Detects torque sensor sub signal
