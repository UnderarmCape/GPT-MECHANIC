DTC U0100, U0122 (Keyless Access Power Control Unit with CAN gateway)

DTC U0100  : Power Control Unit (Body Control Module) Lost Communication with PCM

DTC U0122:  Power Control Unit (Body Control Module) Lost Communication with VSA Modulator-Control Unit (VSA Message)

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • According to the detected DTC(s), check for the power circuit and the ground circuit of the control unit which cannot communicate with the body control module.
  • Refer to the DTC shown on the display, then inspect the connectors and terminals based on the instructions.
DTC Description DTC
U0100 Power Control Unit (Body Control Module) Lost Communication with PCM  
U0122 Power Control Unit (Body Control Module) Lost Communication with VSA Modulator-Control Unit (VSA Message)  

DTC (Power Control Unit)

  1. CAN gateway system DTC check

    -1. Turn the vehicle to the ON mode.

    -2. Check for CAN gateway system DTCs with the HDS.

    DTC Description DTC
    U0029-00 CAN Gateway F-CAN ch A Bus Off  
    U0047-00 CAN Gateway F-CAN ch B Bus Off  
    U3000-49 CAN Gateway Internal Failure  

    DTC (CAN GATEWAY)

    Is DTC U0029-00, U0047-00, and/or U3000-49 indicated?

    YES 

    Go to the troubleshooting for CAN gateway system DTC(s) .

    NO 

    Go to step 2.

  2. F-CAN circuit communication check

    -1. Select the FUNCTION TEST in the CAN gateway with the HDS, then select the F-CAN Bus Connected Unit Check.

    F-CAN Bus Connected Unit Check

    Does the body control module detect the CAN gateway Bus channels A?

    Bus A is Not Available

    Go to step 3.

    Bus A is Available

    Go to step 4.

  3. Open wire check (F-CAN A lines)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    CAN gateway 12P connector *1
    CAN gateway 16P connector *2
    Body control module connector B (36P)

    *1: CAN gateway 12P connector type

    *2: CAN gateway 16P connector type

    -3. Check for continuity between test points 1 and 2 respectively.

    CAN gateway 12P connector type 

    Test condition Vehicle OFF (LOCK) mode
    CAN gateway 12P connector: disconnected
    Body control module connector B (36P): disconnected
    Test point 1 CAN gateway 12P connector No. 3
    Test point 2 Body control module connector B (36P) No. 22
    Test point 1 CAN gateway 12P connector No. 9
    Test point 2 Body control module connector B (36P) No. 23
    Courtesy of HONDA, U.S.A., INC.

    CAN gateway 16P connector type 

    Test condition Vehicle OFF (LOCK) mode
    CAN gateway 16P connector: disconnected
    Body control module connector B (36P): disconnected
    Test point 1 CAN gateway 16P connector No. 3
    Test point 2 Body control module connector B (36P) No. 22
    Test point 1 CAN gateway 16P connector No. 11
    Test point 2 Body control module connector B (36P) No. 23
    Courtesy of HONDA, U.S.A., INC.

    Is there 1.0 Ω or less?

    YES 

    The F-CAN A_H and F-CAN A_L wires are OK. Check for poor connections or loose terminals at the CAN gateway and the body control module. Substitute a known-good body control module , then recheck. If the DTC U0100 goes away and the body control module was substituted, replace the original body control module .

    NO 

    Repair an open in F-CAN A_H or F-CAN A_L wire between the CAN gateway and the body control module.

  4. F-CAN circuit communication check (Transmitting control unit)

    -1. Select the FUNCTION TEST in the CAN gateway with the HDS, then select the F-CAN Bus Connected Unit Check.

    F-CAN Bus Connected Unit Check

    -2. According to the detected DTC on the following table, make sure that the transmitting control unit detects the CAN gateway Bus channel(s) normally.

    DTC Transmitting control unit Detected CAN gateway Bus channel(s) at normal
    U0100 PCM A, B
    U0122 VSA modulator-control unit A, B

    Is it detected normally?

    Detected normal

    Intermittent failure, the system is OK at this time. Check for poor connections or loose terminals at the transmitting control unit and the CAN gateway.

    U0100: PCM is Not Available for Bus A

    Go to step 5.

    U0100: PCM is Not Available for Bus B

    Go to step 6.

    U0122: VSA modulator-control unit is Not Available for Bus A

    Go to step 5.

    U0122: VSA modulator-control unit is Not Available for Bus B

    Go to step 6.

  5. Open wire check (F-CAN A lines)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. U0100: Jump the SCS line with the HDS, and wait more than 1 minute.

    Is there 1.0 Ω or less?

    YES 

    The F-CAN A_H wire and the F-CAN A_L wire are OK.

    Refer to the DTC shown on the display, substitute or replace the control unit based on the instructions (see table).

    DTC Operation for transmitting control unit
    U0100 Substitute a known-good PCM , then recheck. If DTC U0100 goes away and the PCM was substituted, replace the original PCM .
    U0122 Replace the VSA modulator-control unit .

    NO 

    Repair an open in F-CAN A_H or F-CAN A_L wire between the CAN gateway and the transmitting control unit.
