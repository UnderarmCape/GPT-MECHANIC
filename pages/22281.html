DTC P0366 (K20C2)

DTC P0366  : CMP Sensor B and CKP Sensor Incorrect Phase Detected

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • If the DTC P101A stored at the same time as DTC P0366, troubleshoot DTC P101A first, then recheck for DTC P0366.
DTC Description Confirmed DTC Pending DTC
P0366 CMP Sensor B and CKP Sensor Incorrect Phase Detected    

DTC (PGM-FI)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    -3. Turn the vehicle to the OFF (LOCK) mode, and allow the engine to cool below 104 deg.F (40 deg.C).

    -4. Start the engine, and let it idle without load (CVT in P or N, M/T in neutral).

    -5. Check for Pending or Confirmed DTCs with the HDS.

    DTC Description Confirmed DTC Pending DTC
    P0366 CMP Sensor B and CKP Sensor Incorrect Phase Detected    

    Is DTC P0366 indicated?

    YES 

    The failure is duplicated. Go to step 5.

    NO 

    Go to step 2.

  2. VTC system check (VTC TEST with HDS)

    -1. Select the VTC TEST in the INSPECTION MENU with the HDS, then select the EX-VTC.

    VTC TEST - EX-VTC

    Is the result OK?

    YES 

    Go to step 3.

    NO 

    Go to step 5.

  3. VTC system check (VTC STATUS check with HDS)

    -1. Test-drive the vehicle at a steady speed between 19-38 mph (30-60 km/h) for 10 minutes.

    -2. Check the parameter (s) below with the HDS.

    Signal Threshold Current conditions
    Values Unit Values Unit
    EX VTC Status ON      

    Do the current condition (s) match the threshold?

    YES 

    Go to step 4.

    NO 

    Do the test-drive again, then recheck the VTC STATUS.

  4. VTC system check (OBD status check)

    -1. Monitor the OBD STATUS for DTC P0366 in the DTCs MENU with the HDS.

    DTC Description OBD STATUS
    P0366 CMP Sensor B and CKP Sensor Incorrect Phase Detected  

    Does the HDS indicate FAILED?

    YES 

    Go to step 5.

    NO 

    If the HDS indicates PASSED, intermittent failure, the system is OK at this time. If the on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the on-board snapshot . If the HDS indicates NOT COMPLETED, go to step 3, and recheck.

  5. VTC oil control solenoid valve B operation check

    -1. Test VTC oil control solenoid valve B .

    Is the solenoid valve OK?

    YES 

    Go to step 6.

    NO 

    Replace VTC oil control solenoid valve B .

  6. Camshaft timing check

    -1. Check the camshaft timing .

    Is the camshaft timing OK?

    YES 

    Go to step 7.

    NO 

    Reset the camshaft timing .

  7. Cam chain check

    -1. Check for damage or stretch at the cam chain .

    Is the cam chain damaged or stretched?

    YES 

    Replace the cam chain and the auto-tensioner .

    NO 

    Go to step 8.

  8. VTC actuator B check

    -1. Inspect VTC actuator B .

    Is the actuator OK?

    YES 

    Go to step 9.

    NO 

    Replace VTC actuator B .

  9. PGM-FI system check (DTC check)

    -1. Turn the vehicle to the ON mode.

    -2. Reset the PCM with the HDS .

    Reset PCM

    -3. Do the CKP pattern clear procedure .

    CRANK PATTERN CLEAR

    Do the PCM idle learn procedure .

    -5. Do the CKP pattern learn procedure .

    CRANK PATTERN LEARNING

    Turn the vehicle to the OFF (LOCK) mode, and allow the engine to cool below 104 deg.F (40 deg.C).

    -7. Start the engine, and let it idle without load.

    -8. Check for Pending or Confirmed DTCs with the HDS.

    DTC Description Confirmed DTC Pending DTC
    P0366 CMP Sensor B and CKP Sensor Incorrect Phase Detected    

    Is DTC P0366 indicated?

    YES 

    Check for poor connections or loose terminals at VTC oil control solenoid valve B and the PCM, then go to step 1.

    NO 

    Intermittent failure, the system is OK at this time. If the on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the on-board snapshot .
