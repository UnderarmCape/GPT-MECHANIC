LaneWatch Symptom Troubleshooting - Does not switch to the LaneWatch screen

  1. LaneWatch system check (navigation system diagnostic mode)

    -1. Turn the vehicle to the ON mode.

    -2. Do the navigation system diagnostic mode, and select the Detail Information and Setting .

    -3. Select the Unit Check icon.

    Is Connection OK?

    YES 

    Go to step 2.

    NO 

    Check for hard error codes (navigation DTCs) .

  2. LaneWatch switch check (navigation system diagnostic mode)

    -1. Select the Functional Setup icon.

    -2. Select the LaneWatch icon, then operate the LaneWatch switch.

    Is the LaneWatch Switch OK?

    YES 

    Intermittent failure, the system is OK at this time.

    NO 

    Go to step 3.

  3. Open wire check (LANEWATCH SW line)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connector.

    Combination light switch 12P connector

    -3. Connect terminals A and B with a jumper wire.

    Terminal A Combination light switch 12P connector No. 4
    Terminal B Body ground
    Courtesy of HONDA, U.S.A., INC.

    -4. Turn the vehicle to the ON mode.

    -5. Do the navigation system diagnostic mode, and select the Detail Information and Setting .

    -6. Select the Functional Setup icon.

    -7. Select the LaneWatch icon, then operate the LaneWatch switch.

    Is the LaneWatch Switch OK?

    YES 

    Go to step 4.

    NO 

    Repair an open in the LANEWATCH SW wire between the combination light switch and the audio-navigation unit.

  4. Open wire check (GND line)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Remove the jumper wire.

    -3. Connect terminals A and B with a jumper wire.

    Terminal A Combination light switch 12P connector No. 3
    Terminal B Combination light switch 12P connector No. 4
    Courtesy of HONDA, U.S.A., INC.

    -4. Turn the vehicle to the ON mode.

    -5. Do the navigation system diagnostic mode, and select the Detail Information and Setting .

    -6. Select the Functional Setup icon.

    -7. Select the LaneWatch icon, then operate the LaneWatch switch.

    Is the LaneWatch Switch OK?

    YES 

    Replace the combination light switch .

    NO 

    Repair an open in the GND wire between the combination light switch and body ground (G501), or repair poor ground (G501).
