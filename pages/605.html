DTC B12E0

DTC B12E0  : Electric Steering Lock Switch Internal Error

NOTE:  If you are troubleshooting multiple DTCs, be sure to follow the instructions in B-CAN System Diagnosis Test Mode A .

DTC Description DTC
B12E0 Electric Steering Lock Switch Internal Error  

DTC (Power Control Unit)

  1. Problem verification

    -1. Clear the DTCs with the HDS.

    -2. Do this procedure 10 times: Press the engine start/stop switch to select the OFF (LOCK), ACCESSORY, ON, and OFF (LOCK) mode.

    -3. Check for DTCs with the HDS.

    DTC Description DTC
    B12E0 Electric Steering Lock Switch Internal Error  

    Is DTC B12E0 indicated?

    YES 

    Replace the steering lock .

    NO 

    Intermittent failure, the system is OK at this time.
