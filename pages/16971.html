Scan Tool Clear Command

If you are using a generic scan tool to clear commands, be aware that there is only one setting for clearing the PCM, and it clears all commands at the same time (freeze data, fuel learning, on-board snapshot, readiness codes, and DTCs). After you clear all commands, you then need to do these procedures, in this order: Fuel learn procedure ; test-drive to set readiness codes to complete .
