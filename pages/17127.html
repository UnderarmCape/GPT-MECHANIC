DTC B2618, B2619, B261A, B261B

DTC B2618  : Front 1st Sensor Data Failure

DTC B2619  : Front 2nd Sensor Data Failure

DTC B261A  : Front 3rd Sensor Data Failure

DTC B261B  : Front 4th Sensor Data Failure

NOTE: 

  • If you are troubleshooting multiple DTCs, be sure to follow the instructions in B-CAN System Diagnosis Test Mode A .
  • Before you troubleshoot, resetting the parking and back-up sensor control unit .
  • The connection order of the sensor is 1st -> 2nd -> 3rd -> 4th from the side near the control unit.

DTC (Parking and Back-Up Sensor Control Unit)

  1. Problem verification

    -1. Clear the DTCs with the HDS.

    -2. Turn the vehicle to the OFF (LOCK) mode and then the ON mode.

    -3. Wait for at least 6 seconds.

    -4. Check for DTCs with the HDS.

    DTC Description DTC
    B2618 Front 1st Sensor Data Failure  
    B2619 Front 2nd Sensor Data Failure  
    B261A Front 3rd Sensor Data Failure  
    B261B Front 4th Sensor Data Failure  

    Is DTC B2618, B2619, B261A, and/or B261B indicated?

    YES 

    Go to step 2.

    NO 

    Intermittent failure, the system is OK at this time. Check for loose or poor connections.

  2. DTC check

    -1. Check for DTCs with the HDS.

    DTC Description DTC
    B2618 Front 1st Sensor Data Failure  
    B2619 Front 2nd Sensor Data Failure  
    B261A Front 3rd Sensor Data Failure  
    B261B Front 4th Sensor Data Failure  
    B2646 Front Sensor Power Failure  
    B2648 Front Sensor Signal Short to Ground  

    Is DTC B2618, B2619, B261A, B261B, B2646, and/or B2648 indicated?

    YES: B2618, B2619, B261A, and B261B indicated

    Go to step 3.

    YES: B2619, B261A, and B261B indicated

    Go to step 4.

    YES: B261A and B261B indicated

    Go to step 5.

    YES: B261B indicated

    Go to step 6.

    YES: B2646 indicated

    Go to parking and back-up sensor system DTC B2646 troubleshooting .

    YES: B2648 indicated

    Go to parking and back-up sensor system DTC B2648 troubleshooting .

    NO 

    Intermittent failure, the system is OK at this time. Check for loose or poor connections.

  3. Open wire check (BOF SIDE L, SOF SIDE L, E1 SIDE L lines)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    Parking and back-up sensor control unit 16P connector
    Left front corner sensor 6P connector

    -3. Check for continuity between test points 1 and 2 respectively.

    Test condition Vehicle OFF (LOCK) mode
    Parking and back-up sensor control unit 16P connector: disconnected
    Left front corner sensor 6P connector: disconnected
    Test point 1 Parking and back-up sensor control unit 16P connector No. 7
    Test point 2 Left front corner sensor 6P connector No. 6
    Test point 1 Parking and back-up sensor control unit 16P connector No. 6

    Test point 1 Parking and back-up sensor control unit 16P connector No. 13

    Is there 1.0 Ω or less?

    YES 

    Replace the left front corner sensor .

    NO 

    Repair an open or high resistance in the wire.
