DTC U0100, U0101, U0122, U0128, U0131, U0151, U129C (Gauge Control Module with CAN gateway)

DTC U0100  : Gauge Control Module Lost Communication with ENG/AT

DTC U0101  : Gauge Control Module Lost Communication with AT

DTC U0122  : Gauge Control Module Lost Communication with VSA Modulator-Control Unit

DTC U0128  : Gauge Control Module Lost Communication with EPB

DTC U0131  : Gauge Control Module Lost Communication with EPS Unit

DTC U0151  : Gauge Control Module Lost Communication with SRS Unit

DTC U129C  : Gauge Control Module Lost Communication with Multipurpose Camera Unit

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • According to the detected DTC(s), check for the power circuit and the ground circuit of the control unit which cannot communicate with the gauge control module.
  • Refer to the DTC shown on the display, then inspect the connectors and terminals based on the instructions.

DTC (Gauge Control Module)

  1. CAN gateway system DTC check

    -1. Check for CAN gateway system DTCs with the HDS.

    DTC Description DTC
    U0029-00 CAN Gateway F-CAN ch A Bus Off  
    U0047-00 CAN Gateway F-CAN ch B Bus Off  
    U0056-00 CAN Gateway F-CAN ch C Bus Off  
    U3000-49 CAN Gateway Internal Failure  

    DTC (CAN GATEWAY)

    Is DTC U0029-00, U0047-00, U0056-00, and/or U3000-49 indicated?

    YES 

    Go to the troubleshooting for CAN gateway system DTC(s) .

    NO: CAN gateway 12P connector type

    Go to step 2.

    NO: CAN gateway 16P connector type

    Go to step 4.

  2. F-CAN circuit communication check

    -1. Select the FUNCTION TEST in the CAN gateway with the HDS, then select the F-CAN Bus Connected Unit Check.

    F-CAN Bus Connected Unit Check

    Does the gauge control module detect the CAN gateway Bus channels A?

    Bus A is Not Available

    Go to step 3.

    Bus A is Available

    Go to step 6.

  3. Open wire check (F-CAN A lines)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    CAN gateway 12P connector
    Gauge control module connector A (32P)

    -3. Check for continuity between test points 1 and 2 respectively.

    Test condition Vehicle OFF (LOCK) mode
    CAN gateway 12P connector: disconnected
    Gauge control module connector A (32P): disconnected
    Test point 1 CAN gateway 12P connector No. 3
    Test point 2 Gauge control module connector A (32P) No. 19
    Test point 1 CAN gateway 12P connector No. 9
    Test point 2 Gauge control module connector A (32P) No. 20
    Courtesy of HONDA, U.S.A., INC.

    Is there 1.0 Ω or less?

    YES 

    The F-CAN A_H and F-CAN A_L wires are OK. Check for poor connections or loose terminals at the CAN gateway and the gauge control module. Substitute a known-good gauge control module , then recheck. If indicated DTC goes away and the gauge control module was substituted, replace the original gauge control module .

    NO 

    Repair an open in F-CAN A_H or F-CAN A_L wire between the CAN gateway and the gauge control module.

  4. F-CAN circuit communication check

    -1. Select the FUNCTION TEST in the CAN gateway with the HDS, then select the F-CAN Bus Connected Unit Check.

    F-CAN Bus Connected Unit Check

    Go to step 5.

    Bus C is Available

    Go to step 6.

  6. F-CAN circuit communication check (Transmitting control unit)

    -1. Select the FUNCTION TEST in the CAN gateway with the HDS, then select the F-CAN Bus Connected Unit Check.

    F-CAN Bus Connected Unit Check

    -2. According to the detected DTC on the following table, make sure that the transmitting control unit detects the CAN gateway Bus channel(s) normally.

    DTC Transmitting control unit Detected CAN gateway Bus channel(s) at normal
    U0100 PCM A, B
    U0101 TCM A
    U0122
    U0128    		 VSA modulator-control unit A, B
    U0131 EPS control unit B
    U0151 SRS unit B
    DTC Transmitting control unit Detected CAN gateway Bus channel(s) at normal
    U129C Multipurpose camera unit B

    Is it detected normally?

    Detected normal

    Intermittent failure, the system is OK at this time. Check for poor connections or loose terminals at the transmitting control unit and the CAN gateway.
