F-CAN Communication Data 

VSA System Receiving Signal 

Transmitting Unit Signal Name
PCM
  • VSA control enable/disable signal
  • Accelerator pedal position signal
  • Engine speed signal
  • Engine torque signal
  • Neutral position sensor signal *1
  • Brake pedal position switch signal
  • Integrated drive-mode signal *4/*5
  • Service check signal
  • System failure information
TCM *2
  • Shift position signal
  • System failure information
Gauge control module
  • VSA OFF switch signal
  • Brake fluid level switch signal
  • Parking brake switch signal
  • Automatic brake hold switch signal
SRS unit
  • Yaw rate signal
  • Lateral acceleration signal
  • Longitudinal acceleration signal
  • Driver's seat belt buckle switch status
  • System failure information
EPS control unit
  • Steering angle signal
Millimeter wave radar *3
  • Deceleration request signal
  • Brake light relay control request signal
  • System failure information

*1: M/T

*2: CVT

*3: With ACC

*4: Si

*5: Type-R

VSA System Transmitting Signal 

Transmitting Unit Signal Name
VSA modulator-control unit
  • Engine torque control request signal
  • Shift control request signal*
  • System operating state signal
  • Wheel speed signals
  • Master cylinder pressure signal
  • Buzzer request signal
  • Vehicle understeering status
  • Estimated longitudinal acceleration signal
  • Estimated L/R μ differential signal
  • Indicator drive request signal
  • System failure information

*: CVT
