DTC B1602

DTC B1602  : Keyless Access Control Unit (Body Control Module) Internal (EEPROM) Error

NOTE:  If you are troubleshooting multiple DTCs, be sure to follow the instructions in B-CAN System Diagnosis Test Mode A .

DTC Description DTC
B1602 Keyless Access Control Unit (Body Control Module) Internal (EEPROM) Error  

DTC (Keyless Access Control Unit)

  1. Problem verification

    -1. Clear the DTCs with the HDS.

    -2. Turn the vehicle to the OFF (LOCK) mode and then the ON mode.

    -3. Check for DTCs with the HDS.

    DTC Description DTC
    B1602 Keyless Access Control Unit (Body Control Module) Internal (EEPROM) Error  

    Is DTC B1602 indicated?

    YES 

    Replace the body control module .

    NO 

    Intermittent failure, the system is OK at this time.
