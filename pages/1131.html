DTC P0564-15 (2017 2018 2019 2020 2021)

DTC P0564-15  : ACC/LKAS Switch Signal Circuit Open

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • The functions of the integrated driver support system that will be temporarily canceled when this DTC is recorded can be confirmed with the DTC troubleshooting index .
DTC Description DTC
P0564-15 ACC/LKAS Switch Signal Circuit Open  

DTC (IDAS)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    -3. Turn the vehicle to the OFF (LOCK) mode.

    -4. Turn the vehicle to the ON mode, then wait for at least 6 seconds.

    -5. Check for DTCs with the HDS.

    DTC Description DTC
    P0564-15 ACC/LKAS Switch Signal Circuit Open  

    Is DTC P0564-15 indicated?

    YES 

    The failure is duplicated. Go to step 2.

    NO 

    Intermittent failure, the system is OK at this time. Refer to intermittent failures troubleshooting .

  2. Open wire check (LKAS/DIST SW line) 1

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connector.

    ACC combination switch 12P connector

    -3. Turn the vehicle to the ON mode.

    -4. Measure the voltage between test points 1 and 2.

    Test condition Vehicle ON mode
      ACC combination switch 12P connector: disconnected
    Test point 1 ACC combination switch 12P connector (female terminals) No. 12:
    Test point 2 Body ground
    Courtesy of HONDA, U.S.A., INC.

    Is there about 5 V?

    YES 

    Go to step 3.

    NO 

    Go to step 7.

  3. Determine possible failure area (ACC combination switch, CRUISE GND line)

    -1. Measure the voltage between test points 1 and 2.

    Test condition Vehicle ON mode
      ACC combination switch 12P connector: disconnected
    Test point 1 ACC combination switch 12P connector (female terminals) No. 12:
    Test point 2 ACC combination switch 12P connector (female terminals) No. 5:
    Courtesy of HONDA, U.S.A., INC.

    Is there about 5 V?

    YES 

    Replace the ACC combination switch .

    NO 

    Go to step 4.

  4. Open wire check (CRUISE GND line) 1

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connector.

    Cable reel connector C (20P)

    -3. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      ACC combination switch 12P connector: disconnected
      Cable reel connector C (20P): disconnected
    Test point 1 ACC combination switch 12P connector (female terminals) No. 5:
    Test point 2 Cable reel connector C (20P) (female terminals) No. 17:
    Courtesy of HONDA, U.S.A., INC.
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    Go to step 5.

    NO 

    Repair an open in the CRUISE GND wire between the ACC combination switch and the cable reel.

  5. Cable reel check

    -1. Remove the cable reel .

    -2. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      ACC combination switch 12P connector: disconnected
      Cable reel connector C (20P): disconnected
      Cable reel connector A (20P): disconnected
    Test point 1 Cable reel connector A (20P) (male terminals) No. 5:
    Test point 2 Cable reel connector C (20P) (male terminals) No. 17:
    Courtesy of HONDA, U.S.A., INC.
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    Go to step 6.

    NO 

    Replace the cable reel .
