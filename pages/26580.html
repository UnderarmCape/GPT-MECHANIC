HONDA DCA-8000 DYNAMIC DIAGNOSTIC CHARGING SYSTEM UPDATE INFORMATION

HONDA DCA-8000 DYNAMIC DIAGNOSTIC CHARGING SYSTEM UPDATE INFORMATION

TECHNICAL SERVICE BULLETIN

Reference Number(s): 22-060, Date of Issue:  December 15, 2022
HONDA: All Models

INTRODUCTION

The software for the Honda DCA-8000 Dynamic Diagnostic Charging System  is updated periodically to fix software bugs and enhance the tool's functionality. You can update your DCA-8000  via WiFi. It is extremely important to use the latest DCA-8000 software to ensure that the current battery testing and diagnostic procedures are used.

American Honda's policy is to ensure that the DCA-8000  testers are updated promptly. The DCA-8000  software must now be updated within 3 days of receiving notification from an iN message or other Honda communications. If an out-of-date version is used, any battery or alternator replacements will not be covered under warranty. 

DCA-8000 UPDATE REQUIREMENTS

  • Honda DCA-8000 Dynamic Diagnostic Charging System - P/N MTRDCA8000PH
  • Internet access via WiFi. Go to WIFI Setup for requirements.

To order the Honda DCA-8000 Dynamic Diagnostic Charging System  , go to the Honda Tool and Equipment catalog on the iN (select Service > Service Bay > Tool and Equipment > Online Catalog)  , or call 888-424-6857. 

SOFTWARE INFORMATION

The current software version is listed online. Go to the iN (select Service > Service Bay > Diagnostic Tools Software Versions). 

To check the software version on the DCA-8000  , select Settings>scroll down to Information  on the DCA-8000  main menu.

WARRANTY INFORMATION

None. This service bulletin is for information only.

DCA-8000 UPDATE INSTRUCTIONS

WIFI Setup

To update the DCA-8000  , it must be connected to the internet via your service department's WiFi network. WiFi settings can be found in SETTINGS>NETWORK>WIFI  and select AUTOMATIC  to start scanning.

For more information see https://hondadca8000.midtronccs.com/ 

CUSTOMER INFORMATION:  The information in this bulletin is intended for use only by skilled technicians who have the proper tools, equipment, and training to correctly and safely maintain your vehicle. These procedures should not be attempted by "do-it-yourselfers," and you should not assume this bulletin applies to your vehicle, or that your vehicle has the condition described. To determine whether this information applies, contact an authorized Honda automobile dealer.

System Update Prompt

When an update is available via the update server, the user will be prompted with the following screen to download and install the update. Follow the prompts on the screen to proceed with the update.

Manual Update

  1. To manually start the update, select Messages. 
  2. Click OK and let it update.

Download and Installation

DO NOT disconnect or shut off the power during the update, as this could cause damage to the unit. The download/update progress will be displayed on the screen of the unit.

Confirm the software version by selecting VERSION and confirm it matches the iN message for the software release.

NOTE:
  • If you have more than one DCA-8000  , repeat the update procedure for each unit.
  • If you have any problems updating the DCA-8000  , call Midtronics Customer Service at 866-592-8054.
