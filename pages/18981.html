Updating GARMIN Navigation Maps (A17100E)

WARNING: This page is about the Civic EX-L, 2D Coupe, which is a different variant/trim than selected.
Publication date: 2017-10-21
Reference number: A17100E

UPDATING GARMIN NAVIGATION MAPS

UPDATING GARMIN NAVIGATION MAPS

TECHNICAL SERVICE BULLETIN

Reference Number(s): A17100E, Date of Issue:  October 21, 2017
HONDA: All Models

AFFECTED VEHICLES

All models with Display Audio with navigation

Once a year, customers with Display Audio will see this message.

It's telling them it's time to update the Garmin navigation maps. Customers can do the update themselves, but if they're having trouble, you can do it for them.

  • On the iN, go to Service > Service Bay > Navigation Map Updates  and follow the steps.
  • If you need help, call the Garmin Customer Support line at 800-800-1020. Do not call Tech Line; they will direct you to Garmin.
