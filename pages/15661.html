DTC C1650-12 (Type-R) (2017 2018 2019 2020 2021)

DTC C1650-12  : Left-Front Acceleration Sensor Upper Limit Abnormality

NOTE: Before you troubleshoot, review the general troubleshooting information .

DTC Description DTC Freeze Frame
C1650-12 Left-Front Acceleration Sensor Upper Limit Abnormality    

DTC (Adaptive Damper System)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    DTC (Adaptive Damper System)

    -3. Turn the vehicle to the OFF (LOCK) mode, then to the ON mode.

    -4. Wait for 60 seconds or more.

    -5. Check for DTCs with the HDS.

    DTC Description DTC Freeze Frame
    C1650-12 Left-Front Acceleration Sensor Upper Limit Abnormality    

    Is DTC C1650-12 indicated?

    YES 

    The failure is duplicated. Go to step 2.

    NO 

    Intermittent failure, the system is OK at this time. Refer to intermittent failures troubleshooting . If the freeze data/on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the freeze data/on-board snapshot.

  2. Left-rear acceleration sensor performance check

    -1. Check the parameter(s) below with the HDS.

    Signal Current conditions
    Values Unit
    Left Rear Acceleration Sensor Voltage    

    Is there about 5 V?

    YES 

    Repair an open in the wire between the adaptive damper control unit and the front acceleration sensor.

    NO 

    Go to step 3.

  3. Front acceleration sensor check

    -1. Check the front acceleration sensor .

    Is the front acceleration sensor OK?

    YES 

    Go to step 4.

    NO 

    Replace the front acceleration sensor .

  4. Shorted wire check (ADS FR R G line to power)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    Adaptive damper control unit 24P connector
    Front acceleration sensor 3P connector

    -3. Turn the vehicle to the ON mode.

    -4. Measure the voltage between test points 1 and 2.

    Test condition Vehicle ON mode
      Adaptive damper control unit 24P connector: disconnected
      Front acceleration sensor 3P connector: disconnected
    Test point 1 Adaptive damper control unit 24P connector No. 14
    Test point 2 Body ground

    Is there about 5 V or more?

    YES 

    Repair a short to power in the wire between the adaptive damper control unit and the front acceleration sensor.

    NO 

    The ADS FR R G wire is OK. Go to step 5.

  5. Open wire check (ADS SG line)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Adaptive damper control unit 24P connector: disconnected
      Front acceleration sensor 3P connector: disconnected
    Test point 1 Adaptive damper control unit 24P connector No. 15
    Test point 2 Front acceleration sensor 3P connector (female terminals) No. 2:
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    The ADS SG wire is OK. Check for loose terminals and poor connections in the adaptive damper control unit 24P connector. Check for any authorized service information related to the DTCs or symptoms you are troubleshooting. If they are OK, replace the adaptive damper control unit .

    NO 

    Repair an open in the wire between the adaptive damper control unit and the front acceleration sensor.
