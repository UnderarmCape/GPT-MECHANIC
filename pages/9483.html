CHECK SYSTEM Display Indication (CHECK STARTING SYSTEM)

1. If this indicator comes on, the starting system may have had a failure. Connect the HDS to the data link connector (DLC) . Check the diagnostic trouble code (DTC) and note it. Then refer to the indicated DTC's troubleshooting, and begin the appropriate troubleshooting procedure.
