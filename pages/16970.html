HDS Clear Command

The PCM stores various specific data to correct the system even if there is no electrical power such as when the 12 volt battery negative terminal or No. A12 (10 A) fuse is disconnected. Stored data based on failed parts should be cleared by using the CLEAR COMMAND of the HDS, if parts are replaced.

The HDS has two kinds of clear commands to meet this purpose. They are DTC clear and PCM reset. The DTC clear command erases all stored DTCs, freeze data, fuel learning, on-board snapshot, and readiness codes. This must be done with the HDS after reproducing the DTC during troubleshooting. The PCM reset command erases all stored DTCs, freeze data, fuel learning, on-board snapshot, readiness codes, and all specific data to correct the system.
