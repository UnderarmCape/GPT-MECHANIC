PGM-FI System Description - REV Match System (Type-R) (2017 2018 2019 2020 2021)

Overview 

When shifting, optimum engine speed control is performed by the PCM to reduce clutch engagement shock and to reduce driver's shift operation load. And the control is also performed when shifting after coasting that is difficult to fit the engine speed to the transmission speed by the normal shift operation.

Engine rising speed of the REV match system can be changed by the mode on the integrated drive-mode system. And also user can select the REV match system OFF by the user customization menu.

Courtesy of HONDA, U.S.A., INC.

Operation 

The REV match system operates within the following range. And the system prohibits control under the specific condition.

  • In a case of the clutch pedal has been continuously depressed for 8 seconds or more.
  • In a case of actual engine speed reached to target engine speed of REV match control for more than 1 second.
Courtesy of HONDA, U.S.A., INC.

When the REV match system fails, the following indicator comes on in the gauge control module (multi-information display). If the indicator comes on, check for the DTC of the PGM-FI system and the brake system (VSA system). When the REV match system is turned off by the user customization menu, the indicator does not come on.
