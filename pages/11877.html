DTC U0416-68 (EPS Control Unit)

DTC U0416-68  : VSA System Malfunction

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • This DTC is stored by VSA system malfunction. If the VSA indicator on, troubleshoot the VSA system first.
DTC Description DTC Freeze Frame
U0416-68 VSA System Malfunction    

DTC (EPS)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    Clear DTCs

    -3. Turn the vehicle to the OFF (LOCK) mode, then start the engine.

    -4. Wait for 60 seconds or more.

    -5. Check for DTCs with the HDS.

    DTC Description DTC Freeze Frame
    U0416-68 VSA System Malfunction    

    Is DTC U0416-68 indicated?

    YES 

    The failure is duplicated. Go to VSA system troubleshooting .

    NO 

    Intermittent failure, the system is OK at this time. If the freeze data/on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the Freeze data/on-board snapshot.
