    Note for installation 

    1. Install the two 20 x 1.5 mm nuts (A) onto the oil filter feed pipe. Hold the nut with a wrench, then tighten the other nut.

    2. Apply new engine oil to the oil filter feed pipe threads.

    Courtesy of HONDA, U.S.A., INC.

    3. Install the oil filter feed pipe in its specified height range shown.

    4. Remove the nuts from the oil filter feed pipe.

  3. All Removed Parts - Install
    1. Install the parts in the reverse order of removal.
