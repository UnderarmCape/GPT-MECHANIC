Mis-Fuel Inhibit Device Removal and Installation (2016 2017 2018): Removal

WARNING: 

Flammable - Keep Fire Away

NOTE:  Refer to the Fuel and Emissions Systems Service Precautions before disconnecting the fuel line.

  1. Fuel Fill Door Adapter - Remove
  2. Mis-Fuel Inhibit Device - Remove
    Courtesy of HONDA, U.S.A., INC.HONDA, U.S.A., INC.
    Courtesy of HONDA, U.S.A., INC.HONDA, U.S.A., INC.
    		 1. Break the six lock tabs (A).

    2. Pry up the lock tab (B), then remove the mis-fuel inhibit device (C).

    NOTE:  Never reuse the mis-fuel inhibit device.
  3. Main Flap Unit - Remove (If necessary)

    1. Set the capless wrench and slightly turn the main flap unit (A) counterclockwise.

    NOTE: 

    • The main flap unit may move only a small amount. This is normal.
    • Depending on the emission type, the main flap unit and wrench may be positioned in either direction as shown (B).
    Courtesy of HONDA, U.S.A., INC.

    2. Remove the capless wrench and install the flapper retainer onto the main flap unit (A) as shown to keep the flap open.

    Courtesy of HONDA, U.S.A., INC.

    3. Insert the capless pick under the lock tab (A) and release the lock by turning the pick counterclockwise.

    NOTE:  The lock tab is unlocked when it folds inside the filler neck opening.

    Courtesy of HONDA, U.S.A., INC.

    4. Set the capless wrench onto the main flap unit (A) as shown.

    NOTE:  It may be necessary to move the flapper retainer slightly to install the capless wrench.

    Courtesy of HONDA, U.S.A., INC.

    5. Turn the main flap unit clockwise until it stops, then remove it.

    NOTE:  If the lock tab was disengaged properly, the main flap unit should turn easily. If you feel resistance, remove the capless wrench and confirm that the lock tab was disengaged.
