Exterior Lights System Description - Failsafe Function

Automatic Lighting System 

When an automatic lighting sensor failure occurs, the system maintains the state before the automatic lighting sensor failure, and a warning is displayed in the multi-information display (MID) or the warning indicator turns on in the gauge control module.
