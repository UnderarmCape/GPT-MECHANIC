Removal and Installation

NOTE:  The under-hood fuse/relay box is a part of the engine compartment wire harness, and it cannot be replaced by itself.

  1. PCM - Remove
  2. 12 Volt Battery Terminal - Disconnect 
  3. Relay Circuit Board - Remove 
  4. Under-Hood Fuse/Relay Box - Remove
    Courtesy of HONDA, U.S.A., INC.
    		 1. Disconnect the cables (A).

    2. Remove the under-hood fuse/relay box (B) from the bracket (C).

    3. Cut the bands (D).

    4. Remove the bottom covers (E) from the under-hood fuse/relay box.

    5. Remove the fuse(s) (F).

    6. Carefully remove the relays using the relay puller tool.

    NOTE:  Do not use pliers. Pliers will damage the relays, which could cause the engine to stall, not start, or cause other functions to fail.
  5. All Removed Parts - Install
    1. Install the parts in the reverse order of removal.
