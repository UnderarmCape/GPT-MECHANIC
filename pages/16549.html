DTC P2583-87 (2/4-door) (2016 2017 2018)

DTC P2583-87  : Lost Communication With The Millimeter Wave Radar

NOTE:  Before you troubleshoot, review the general troubleshooting information .

DTC Description DTC Freeze Frame
P2583-87 Lost Communication With The Millimeter Wave Radar    

DTC (IDAS)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    -3. Turn the vehicle to the OFF (LOCK) mode, then the ON mode.

    -4. Check for DTCs with the HDS.

    DTC Description DTC Freeze Frame
    P2583-87 Lost Communication With The Millimeter Wave Radar    

    Is DTC P2583-87 indicated?

    YES 

    The failure is duplicated. Go to step 2.

    NO 

    Intermittent failure, the system is OK at this time. Refer to intermittent failures troubleshooting . If the freeze data/on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the freeze data/on-board snapshot.

  2. Fuse check

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Check the following fuse.

    Fuse No. B5 (10 A)
    Location Under-dash fuse/relay box

    Is the fuse OK?

    YES 

    The fuse is OK. Reinstall the fuse, then go to step 3.

    NO 

    Replace the fuse. Turn the vehicle to the ON mode, then the OFF (LOCK) mode. If the fuse blows again, repair a short to ground in the No. B5 (10 A) fuse circuit.

  3. Open wire check (IG1 OPTION line)

    -1. Disconnect the following connector.

    Millimeter wave radar 10P connector

    -2. Turn the vehicle to the ON mode.

    -3. Measure the voltage between test points 1 and 2.

    Test condition Vehicle ON mode
      Millimeter wave radar 10P connector: disconnected
    Test point 1 Millimeter wave radar 10P connector terminal No. 5
    Test point 2 Body ground
    Courtesy of HONDA, U.S.A., INC.

    Is there battery voltage?

    YES 

    Go to step 4.

    NO 

    Repair an open in the IG1 OPTION wire between the under-dash fuse/relay box and the millimeter wave radar.

  4. Open wire check (GND line)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Millimeter wave radar 10P connector: disconnected
    Test point 1 Millimeter wave radar 10P connector No. 1
    Test point 2 Body ground
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    Go to step 5.

    NO 

    Repair an open in the GND wire between the millimeter wave radar and ground (G401), or repair poor ground (G401).

  5. Open wire check (ACC CAN-L, ACC CAN-H lines)

    -1. Disconnect the following connector.

    Multipurpose camera unit 20P connector

    -2. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Millimeter wave radar 10P connector: disconnected
      Multipurpose camera unit 20P connector: disconnected
    Test point 1 Multipurpose camera unit 20P connector No. 7
    Test point 2 Millimeter wave radar 10P connector No. 3
    Test point 1 Multipurpose camera unit 20P connector No. 18
    Test point 2 Millimeter wave radar 10P connector No. 2
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    Go to step 6.

    NO 

    Repair an open in the ACC CAN-H wire or the ACC CAN-L wire between the multipurpose camera unit and the millimeter wave radar.

  6. Shorted wire check (ACC CAN-L, ACC CAN-H lines)

    -1. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Millimeter wave radar 10P connector: disconnected
      Multipurpose camera unit 20P connector: disconnected
    Test point 1 Millimeter wave radar 10P connector No. 3
    Test point 2 Body ground
    Test point 1 Millimeter wave radar 10P connector No. 2
    Test point 2 Body ground
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    Repair a short to ground in the ACC CAN-H wire or the ACC CAN-L wire between the millimeter wave radar and multipurpose camera unit.

    NO 

    Replace the millimeter wave radar .
