LaneWatch Camera Aiming: Adjustment

NOTE: 

  • The LaneWatch camera must be aimed after one or more of the following procedures are done:
    • -

      LaneWatch camera removal or replacement

    • -

      Passenger's side power mirror removal or replacement

    • -

      Passenger's side mirror housing lower cover removal or replacement

    • -

      Passenger's side door position adjustment

  • Set up the vehicle:
    • -

      Install an aiming target on the passenger's side of the vehicle.

    • -

      Do the aiming in a proper place where you can obtain the about 4.5 m (14.8 ft) distance between a target pattern and the vehicle (from the center of the front wheel hub).

  • Prepare these items:
    • -

      Tape measure and ruler

    • -

      Felt-tip pen

    • -

      Tape

    • -

      String

  • Park the vehicle on floor surface in a width open area to avoid any reflection from objects that could affect the alignment procedure. Make sure you have at least the following amount of space around the vehicle: 6.5 m (21.3 ft) in length, 3.5 m (11.5 ft) in width.
Courtesy of HONDA, U.S.A., INC.
  • When marking on the floor surface, use suitable tape to mark the exact locations.
  1. Before Aiming - Set
  2. Aiming Marker - Set
    Courtesy of HONDA, U.S.A., INC.
    		 NOTE: 
    • Make sure there are no other objects except the aiming target in this area.
    • Check the tire pressures, and adjust them to the specified value if needed.
    • Have the driver sit in the driver's seat, or put an object equivalent to the driver's weight in the driver's seat.

    1. Set the aiming marker (A) to the LaneWatch aiming stand (B), and adjust the height of the aiming marker.
    Courtesy of HONDA, U.S.A., INC.
    		 2. Pull a string (A) between point Z1 and point Y1, and tape both ends of the string on the floor surface.

    NOTE:  Repeat this step for the opposite wheels, and pull a string on the floor surface.

    3. Measure and make new spot B on the floor surface in rear of the vehicle 4, 500 mm (177.17 in) from the point Z1.

    NOTE:  Repeat this step for the opposite front wheel, and mark new spot C on the floor surface.
    Courtesy of HONDA, U.S.A., INC.
    		 4. Stretch a string (A) between point B and point C, and tape both ends of the string on the floor surface. Mark new point D where the string crosses with the center-line (E).

    5. On the string (A), mark new point F (target of the passenger's side) which is 1, 300 mm (51.18 in) from point D to the passenger's side.
    Courtesy of HONDA, U.S.A., INC.
    		 6. Place the left side edge of the aiming marker (A) on the mark that you made in the previous step. Align the legs of the marker with the tape measure to make sure the marker is square to the vehicle.
  3. LaneWatch Camera - Aim
    NOTE: 
    • When you stop the aiming procedure, turn the vehicle to the OFF (LOCK) mode.
    • If the aiming procedure fails, brighten or darken the ambient lighting in case the lighting is affecting the aiming.

    1. Display Select Diagnosis Items Menu Screen, and select the LaneWatch aiming start icon

    2. Press the LaneWatch switch on the end of the turn signal switch to aim the camera.

    3. Wait until the aiming process is complete, and the display returns to the LaneWatch camera image.
