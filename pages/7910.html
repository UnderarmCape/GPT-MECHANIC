DTC P0011 (K20C1) (2017 2018 2019 2020 2021)

DTC P0011  : VTC A System Malfunction

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • If DTC P0010 and/or P0016 are stored at the same time as DTC P0011, troubleshoot those DTCs first, then recheck for DTC P0011.
DTC Description Confirmed DTC Pending DTC
P0011 VTC A System Malfunction    

DTC (PGM-FI)

  1. Oil pressure check

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    Clear DTC

    -3. Start the engine.

    -4. Watch the low oil pressure indicator in the gauge with the engine running.

    Is the low oil pressure indicator on?

    YES 

    Check the engine oil level. If the level is OK, check the engine oil pressure .

    NO 

    Go to step 2.

  2. Problem verification

    -1. Select the VTC TEST in the INSPECTION MENU with the HDS, then select the IN-VTC.

    VTC TEST

    Is the result OK?

    YES 

    The failure is not duplicated. Go to step 3.

    NO 

    Go to step 5.

  3. VTC system check (HDS data list check)

    -1. Start the engine.

    -2. Check the parameter(s) below with the HDS.

    Signal Threshold Current conditions
    Values Unit Values Unit
    VTC STATUS ON      

    Do the current condition(s) match the threshold?

    YES 

    Go to step 4.

    NO 

    Go to step 3-1, and recheck.

  4. VTC system check (OBD STATUS check)

    -1. Start the engine.

    -2. Monitor the OBD STATUS for DTC P0011 with the HDS.

    DTC Description OBD STATUS
    P0011 VTC A System Malfunction  

    Does the HDS indicate FAILED?

    YES 

    Go to step 5.

    NO 

    If the HDS indicates PASSED, intermittent failure, the system is OK at this time. Check for poor connections or loose terminals at VTC oil control solenoid valve A and the PCM. If the on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the on-board snapshot . If the HDS indicates NOT COMPLETED, go to step 2 and recheck.

  5. VTC oil control solenoid valve A check

    -1. Test the VTC oil control solenoid valve A .

    Is the valve OK?

    YES 

    Go to step 6.

    NO 

    Replace VTC oil control solenoid valve A .

  6. VTC actuator A check

    -1. Inspect VTC actuator A .

    Is the VTC actuator A OK?

    YES 

    Check the VTC system oil passages and the VTC oil control bolt, and clean them if needed.

    NO 

    Replace VTC actuator A .
