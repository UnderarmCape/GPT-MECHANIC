VSA System Description - Overview

The VSA system stabilizes the vehicle behavior by controlling the braking force and engine torque.

The VSA system consists of the following primary components:

  • VSA modulator-control unit
  • Wheel speed sensors
  • Magnetic encoders
  • VSA OFF switch
  • Automatic brake hold switch
  • System indicator

For locations of each component on vehicle, refer to Component Location Index , and for functions of indicator, refer to How to Troubleshoot the VSA System .

The VSA system performs the following controls. And also if a vehicle is equipped with the ACC and the CMBS, the VSA system performs brake control for the ACC and the CMBS.

Integrated Drive-Mode System (Si) 

When the integrated drive-mode system is in the SPORT mode, the agile handling assist control improves the line traceability in cornering, and the TCS control increases the driver's control range by allowing wheel slip.

Integrated Drive-Mode System (Type-R) 

When the integrated drive-mode system is in the +R mode, the agile handling assist control improves the line traceability in cornering, and the TCS control increases the driver's control range by allowing wheel slip. When the integrated drive-mode system is in the +R mode and the VSA system is in FULLY OFF mode, the VSA system turns off the TCS control and the VSA control, and increases the driver's control range more.
