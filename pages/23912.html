  1. VTC Actuator A - Install
    Courtesy of HONDA, U.S.A., INC.
    		 NOTE:  If removed VTC actuator A, do this procedure.

    1. Install VTC actuator A.

    2. Apply new engine oil to the threads of the VTC actuator A mounting bolt (B), then loosely install it.
  2. VTC Actuator B - Install
    Courtesy of HONDA, U.S.A., INC.
    		 NOTE:  If removed VTC actuator B, do this procedure.

    1. Install VTC actuator B.

    2. Apply new engine oil to the threads of the VTC actuator B mounting bolt (A), then loosely install it.
  3. Intake Camshaft - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Turn the crankshaft so its white mark (A) on the crankshaft pulley lines up with the pointer (B) on the cam chain case.

    2. Install the intake camshaft.
  4. Lower Exhaust Camshaft Holder - Install
  5. Exhaust Camshaft - Install
    Courtesy of HONDA, U.S.A., INC.HONDA, U.S.A., INC.
    Courtesy of HONDA, U.S.A., INC.HONDA, U.S.A., INC.
    		 1. Slide the exhaust camshaft in at an angle to allow the cam chain to slip over the teeth.

    2. Set the No. 1 piston at top dead center (TDC). The "UP" mark (A) on VTC actuator B should be at the top. Align the TDC marks (B) on VTC actuator A and VTC actuator B. The TDC marks (C) on VTC actuator B should line up with the top edge of the cam chain case (D).

    3. Apply new engine oil to the camshaft journals and the cam lobes on both camshafts.
  6. Cam Chain Guide B, Intake Camshaft Holder, and Upper Exhaust Camshaft Holder - Install
    Fig 3: Camshaft Holder Bolts With Tightening Sequence
    Courtesy of HONDA, U.S.A., INC.HONDA, U.S.A., INC.HONDA, U.S.A., INC.
    1. Apply new engine oil to the threads of the camshaft holder bolts.

    2. Tighten the camshaft holder bolts, in sequence, to the specified torque.
    Courtesy of HONDA, U.S.A., INC.
    		 3. If removed VTC actuator A, hold the intake camshaft with an open-end wrench, then tighten the VTC actuator A mounting bolt to the specified torque.
    Courtesy of HONDA, U.S.A., INC.
    		 4. If removed VTC actuator B, hold the exhaust camshaft with an open-end wrench, then tighten the VTC actuator B mounting bolt to the specified torque.

  8. Camshaft Timing - Check
  9. Valve Clearance - Adjust
  10. High Pressure Fuel Pump Base - Install

    NOTE: Apply liquid gasket  to the No. 5 rocker shaft holder mating surface of the high pressure fuel pump base and to the inside edge of the threaded bolt holes.

    1. Turn the vehicle to the ON mode, but do not start the engine. After the fuel pump runs for about 2 seconds, the fuel line will be pressurizesd. Repeat this two or three times, then check for fuel leakage.
