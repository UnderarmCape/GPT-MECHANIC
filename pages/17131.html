DTC B2648

DTC B2648  : Front Sensor Signal Short to Ground

NOTE: 

  • If you are troubleshooting multiple DTCs, be sure to follow the instructions in B-CAN System Diagnosis Test Mode A .
  • The connection order of the sensor is 1st -> 2nd -> 3rd -> 4th from the side near the control unit.
DTC Description DTC
B2648 Front Sensor Signal Short to Ground  

DTC (Parking and Back-Up Sensor Control Unit)

  1. Problem verification

    -1. Clear the DTCs with the HDS.

    -2. Turn the vehicle to the OFF (LOCK) mode and then the ON mode.

    -3. Wait for at least 6 seconds.

    -4. Check for DTCs with the HDS.

    DTC Description DTC
    B2648 Front Sensor Signal Short to Ground  

    Is DTC B2648 indicated?

    YES 

    Go to step 2.

    NO 

    Intermittent failure, the system is OK at this time. Check for loose or poor connections.

  2. Shorted wire check (SOF SIDE L, E1 SIDE L lines) 1

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connector.

    Parking and back-up sensor control unit 16P connector

    -3. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
    Parking and back-up sensor control unit 16P connector: disconnected
    Test point 1 Parking and back-up sensor control unit 16P connector No. 6
    Test point 2 Parking and back-up sensor control unit 16P connector No. 13

    Is there 1 MΩ or more?

    YES 

    Go to step 10.

    NO 

    Go to step 3.

  3. Shorted wire check (SOF SIDE R, E1 SIDE R lines) 1

    -1. Disconnect the following connector.

    Right front center sensor 6P connector

    -2. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
    Parking and back-up sensor control unit 16P connector: disconnected
    Right front center sensor 6P connector: disconnected
    Test point 1 Right front center sensor 6P connector No. 3
    Test point 2 Right front center sensor 6P connector No. 1
    Courtesy of HONDA, U.S.A., INC.

    YES 

    Go to step 5.

    NO 

    Go to step 4.

    YES

    NO 

    Repair a short in the SOF SIDE R and E1 SIDE R wires between the right front center sensor and the right front corner sensor.
