Keyless/Power Door Locks/Security System Symptom Troubleshooting - AUTO DOOR UNLOCK does not work (4-door)

NOTE: 

  • Before testing, make sure the No. A1-5*1, No. A2-2, and No. A18 fuses are OK.
  • Check if Auto Door Unlock feature selected OFF, under MID customized settings for each remote transmitter: Driver 1 and 2.

    Make sure to test operation of each Auto Door Unlock setting to check function.

  • Before testing, make sure the No. B8, No. B9, No. B11*2, No. B12, No. B13, No. B15, No. B16, No. B25, No. B26, No. B28, No. B38, and No. B39 fuses are OK.
  • There are two pairs of fuses in the same circuit (No. B25 and No. B39 fuses, No. B12 and No. B26 fuses, No. B13 and No. B38 fuses). If one fuse is blown, make sure to check the other fuse in the same circuit. If necessary, replace the blown fuse(s).

    *1: With keyless access system

    *2: Except L15BY engine

    -1. Connect the HDS to the data link connector (DLC) .

    -2. Select DOOR LOCKS from the BODY ELECTRICAL SYSTEM SELECT menu with the HDS, and enter FUNCTIONAL TESTS.

    BODY ELECTRICAL - DOOR LOCKS - Functional Tests - Inspection

    -3. Select UNLOCK ALL DOORS with the HDS.
