DTC C1645-14 (Type-R) (2017 2018 2019 2020 2021)

DTC C1645-14  : Right-Front Stroke Sensor Lower Limit Abnormality

NOTE: Before you troubleshoot, review the general troubleshooting information .

DTC Description DTC Freeze Frame
C1645-14 Right-Front Stroke Sensor Lower Limit Abnormality    

DTC (Adaptive Damper System)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    Clear DTCs

    -3. Turn the vehicle to the OFF (LOCK) mode, then to the ON mode.

    -4. Wait for 60 seconds or more.

    -5. Check for DTCs with the HDS.

    DTC Description DTC Freeze Frame
    C1645-14 Right-Front Stroke Sensor Lower Limit Abnormality    

    Is DTC C1645-14 indicated?

    YES 

    The failure is duplicated. Go to step 2.

    NO 

    Intermittent failure, the system is OK at this time. Refer to intermittent failures troubleshooting . If the freeze data/on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the freeze data/on-board snapshot.

  2. Open wire check (ADS SVCC line)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    Adaptive damper control unit 24P connector
    Right-front suspension stroke sensor 3P connector

    -3. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Adaptive damper control unit 24P connector: disconnected
      Right-front suspension stroke sensor 3P connector: disconnected
    Test point 1 Adaptive damper control unit 24P connector No. 17
    Test point 2 Right-front suspension stroke sensor 3P connector (female terminals) No. 3:
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    Go to step 3.

    NO 

    Repair an open in the wire between the adaptive damper control unit and the right-front suspension stroke sensor.

  3. Shorted wire check (ADS SVCC line)

    -1. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Adaptive damper control unit 24P connector: disconnected
      Right-front suspension stroke sensor 3P connector: disconnected
    Test point 1 Right-front suspension stroke sensor 3P connector (female terminals) No. 3:
    Test point 2 Body ground
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    Repair a short to body ground in the wire between the adaptive damper control unit and the right-front suspension stroke sensor.

    YES 

    The ADS SVCC wire is OK. Go to step 4.

  4. Open wire check (ADS FR R STROKE/ADJ SNSR FR SIG line)

    -1. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Adaptive damper control unit 24P connector: disconnected
      Right-front suspension stroke sensor 3P connector: disconnected
    Test point 1 Adaptive damper control unit 24P connector No. 18
    Test point 2 Right-front suspension stroke sensor 3P connector (female terminals) No. 2:
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    The ADS FR R STROKE/ADJ SNSR FR SIG wire is not open. Go to step 5.

    NO 

    Repair an open in the wire between the adaptive damper control unit and the right-front suspension stroke sensor.

  5. Shorted wire check (ADS FR R STROKE/ADJ SNSR FR SIG line)

    -1. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Adaptive damper control unit 24P connector: disconnected
      Right-front suspension stroke sensor 3P connector: disconnected
    Test point 1 Right-front suspension stroke sensor 3P connector (female terminals) No. 2:
    Test point 2 Body ground
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    Repair a short to body ground in the wire between the adaptive damper control unit and the right-front suspension stroke sensor.

    NO 

    The ADS FR R STROKE/ADJ SNSR FR SIG wire is OK. Go to step 6.

  6. Adaptive damper control unit check

    -1. Substitute a known-good adaptive damper control unit .

    -2. Reconnect all connectors.

    -3. Turn the vehicle to the ON mode.

    -4. Clear the DTC with the HDS.

    Clear DTCs

    -5. Turn the vehicle to the OFF (LOCK) mode, then to the ON mode.

    -6. Wait for 60 seconds or more.

    -7. Check for DTCs with the HDS.

    DTC Description DTC Freeze Frame
    C1645-14 Right-Front Stroke Sensor Lower Limit Abnormality    

    Is DTC C1645-14 indicated?

    YES 

    Replace the right-front suspension stroke sensor .

    NO 

    Replace the original adaptive damper control unit .
