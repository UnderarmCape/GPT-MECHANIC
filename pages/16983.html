DTC P0014 (L15B7/L15BA/L15BY)

DTC P0014  : VTC B System Malfunction

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • If DTC P0013 and/or P0366 are stored at the same time as DTC P0014, troubleshoot those DTCs first, then recheck for DTC P0014.
DTC Description Confirmed DTC Pending DTC
P0014 VTC B System Malfunction    

DTC (PGM-FI)

  1. Oil pressure check

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    Clear DTC

    -3. Start the engine.

    -4. Watch the low oil pressure indicator in the gauge with the engine running.

    Is the low oil pressure indicator on?

    YES 

    Check the engine oil level. If the level is OK, check the engine oil pressure .

    NO 

    Go to step 2.

  2. Problem verification

    -1. Select the VTC TEST in the INSPECTION MENU with the HDS, then select the EX-VTC.

    VTC TEST - EX-VTC

    Is the result OK?

    YES 

    The failure is not duplicated. Go to step 3.

    NO 

    Go to step 5.

  3. VTC system check (HDS data list check)

    -1. Test-drive the vehicle at a steady speed between 19-37 mph (30-60 km/h) for 10 minutes.

    -2. Check the parameter(s) below with the HDS.

    Signal Threshold Current conditions
    Values Unit Values Unit
    EX VTC Status ON      

    Do the current condition(s) match the threshold?

    YES 

    Go to step 4.

    NO 

    Go to step 3, and recheck.

  4. VTC system check (OBD STATUS check)

    -1. Test-drive the vehicle at a steady speed between 19-37 mph (30-60 km/h) for 10 minutes.

    -2. Monitor the OBD STATUS for DTC P0014 with the HDS.

    DTC Description OBD STATUS
    P0014 VTC B System Malfunction  

    Does the HDS indicate FAILED?

    YES 

    Go to step 5.

    NO 

    If the HDS indicates PASSED, intermittent failure, the system is OK at this time. Check for poor connections or loose terminals at VTC oil control solenoid valve B and the PCM. If the on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the on-board snapshot . If the HDS indicates NOT COMPLETED, go to step 2 and recheck.

  5. VTC oil control solenoid valve B check

    -1. Test VTC oil control solenoid valve B .

    Is the solenoid valve OK?

    YES 

    Check the VTC system oil passages, and clean them if needed.

    NO 

    Replace VTC oil control solenoid valve B .
