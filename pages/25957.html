Removal and Installation

Door Speaker 

  1. Door Panel - Remove
    1. Remove the door panel:
    • Front door panel
    • Rear door panel
  2. Door Speaker - Remove
    Courtesy of HONDA, U.S.A., INC.
    		 1. Remove the bolt (A), then lift the door speaker (B) straight up to release the lower clips (C).

    2. Disconnect the connector (D).
  3. All Removed Parts - Install
    1. Install the door speaker in the reverse order of removal.

Front Tweeter 

  1. Front Door Panel - Remove
  2. Tweeter Cover - Remove
    Courtesy of HONDA, U.S.A., INC.

    2. Disconnect the connector (B).
  3. Front Tweeter - Remove
    Courtesy of HONDA, U.S.A., INC.
  4. All Removed Parts - Install
    1. Install the front tweeter in the reverse order of removal.
