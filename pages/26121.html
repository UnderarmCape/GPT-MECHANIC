Millimeter Wave Radar Aiming (4-door, Japan Production) (2018): Adjustment

NOTE: 

  • The millimeter wave radar must be re-aimed if the millimeter wave radar is removed or replaced. The ACC indicator comes on if the aiming process is not completed correctly.
    • -

      Two kinds of aiming procedures must be performed for the radar to be re-aimed; the vertical radar aiming and the horizontal radar aiming, electronically done using the HDS.

    • -

      The millimeter wave radar has a self-diagnosis function and if the mounting angle of the millimeter wave radar is outside of the horizontal auto-aiming range, it sends the failure information to the multipurpose camera unit.

  • If DTCs are indicated, do the indicated DTCs first. If the DTCs are not repaired, you cannot complete the millimeter wave radar aiming procedure. However, if you have the following DTC, proceed with the aiming procedure.
    • -

      Millimeter Wave Radar Aiming Incomplete: DTC P2583-54

  • If the vehicle you are aiming was involved in a collision or if you suspect the alignment is out of specifications, you must perform a wheel alignment prior to aiming the millimeter wave radar.
  • Conditions for the aiming environment:
    • -

      Aiming should be on level ground in a wide open space to avoid errors caused by reflecting objects.

    • -

      Amount of space require in front of the vehicle: 10 m (33 ft) measured from the front bumper4 m (13 ft) in width1.5 m (4.9 ft) in height, measured from the floor surface

  • The vehicle must be parked on a horizontal floor in order to adjust the vertical radar aiming correctly. Check the levelness of the floor surface, but if there is a continuous slope, then adjust the angle of the millimeter wave radar so it is parallel to the floor surface. Lay a ruler or other flat straight object on the floor surface and put the level on top to confirm the levelness of the floor surface.
  • When marking on the floor, use suitable tape to mark the exact locations.

Prepare these items:

  • HDS
  • Tape measure and ruler
  • Felt-tip pen
  • Tape
  • String
  • Plumb bob

  2. Millimeter Wave Radar - Vertical Radar Aim
    Courtesy of HONDA, U.S.A., INC.
    		 1. Connect the HDS .

    NOTE:  Troubleshoot any DTCs first before proceeding. If DTC P2583-54 is indicated, proceed with the aiming procedure.

    2. Check for DTCs with the HDS.

    3. In the DRIVING SUPPORT MENU, select INTEGRATED DRIVER SUPPORT SYSTEM, then ADJUSTMENT, then select Radar Aiming on the HDS.

    4. Select "Enter" to start vertical aiming on the HDS.

    NOTE:  Keep the stand set away from the front of the vehicle until you are instructed in a later step.

    5. The MID will indicate the number 3 on the display for a few seconds.

    NOTE:  If an error message appears on the HDS, the stand set is placed in front of the vehicle or there is an unwanted radar reflection in front of the vehicle in the range of the radar. Make sure the stand set is set aside away from the range of the radar until you are instructed to place it in front of the vehicle. If you are still getting an unwanted radar reflection, stack tires about 1.5 m (4.9 ft) in height in front of either the immovable object, such as a pole, or in front of any object causing the unwanted reflections. The tires will block the radar reflections. Make sure the error message does not appear on the HDS. If it still appears, move the vehicle to a different location until the error message does not appear on the HDS.

    6. Position the stand set to align the hole (E) of the stand set with the point (F). Make sure that you can see the mark through the hole.

    Courtesy of HONDA, U.S.A., INC.
    Courtesy of HONDA, U.S.A., INC.
    		 7. Set the reflector (A) of the stand set to position Y1, then select "Enter" on the HDS.
    Courtesy of HONDA, U.S.A., INC.
    		 8. Set the reflector (A) of the stand set to position Y2, then select "Enter" on the HDS.

    10. The HDS will display the current angle of the millimeter radar. If the angle is not within the specified angle of 0

    More than +0.1 deg. Rotate the 3.5 mm hex socket driver clockwise
    Less than -0.1 deg. Rotate the 3.5 mm hex socket driver counterclockwise

    NOTE: 

    • The values on the HDS display will fluctuate while the adjustment is being performed. Wait until the values stabilize to confirm the adjustment.
    • During adjustment, do not enter or obstruct the radar wave zone.
    • A value of 12.8 degrees on the HDS displays indicates that the millimeter wave radar is being obstructed and cannot receive the radar wave.
    • If the HDS indicates a value of more than +2.0 degrees or less than -2.0 degrees, do the following:
      • -

        Turn the adjusting bolt as indicated in the chart below.

      • -

        Turn the vehicle to the OFF (LOCK) mode to abort the vertical aiming.

      • -

        Restart the vertical aiming procedure from step 3.

      • -

        If the HDS still indicates a value that is more than +2.0 degrees or less than -2.0 degrees, inspect the millimeter wave radar mounting position .

    Angle shown on the HDS display  Rotate the 3.5 mm hex socket driver as follows 
    More than +2.0 deg. Rotate the 3.5 mm hex socket driver 2 1/2 times clockwise
    Less than -2.0 deg. Rotate the 3.5 mm hex socket driver 2 1/2 times counterclockwise
    Courtesy of HONDA, U.S.A., INC.

    11. If the MID indicates an aiming failure code, refer to the table below. Then repeat the vertical aiming procedure.

    NOTE:  The aiming failure code is not stored and cannot be read with the HDS, so note the code before turning the vehicle to the OFF (LOCK) mode.

    Aiming failure code (on the MID)  Cause  How to solve 
    120 Two or more aiming targets exist. Remove all reflective objects except the correct special tools, and repeat the aiming procedure.
    122 The distance of the aiming target is out of specification. Set the distance to the aiming target 3, 850-4, 150 mm (151.57-163.39 in), and repeat the aiming procedure.
    124 The angle of the millimeter wave radar is exceeding the adjustable range or the height of the aiming target is out of the specified range. Inspect and adjust the millimeter wave radar mounting position  or the height of the aiming target to the specified height and repeat the aiming procedure.
    125 There is no aiming target. Reset the aiming target at the correct position, and repeat the aiming procedure.

    12. After adjustment, select "Enter", then go to the horizontal aiming.

  3. Millimeter Wave Radar - Horizontal Radar Aim
    Courtesy of HONDA, U.S.A., INC.
    		 1. Move the stand set from the front of the vehicle, then start the horizontal aiming.

    2. The MID will display NO TARGET.

    3. Make sure the MID indicates NO TARGET on its display.

    NOTE:  If NO TARGET is not indicated, the radar aimer set is placed in front of the vehicle or there is an unwanted radar reflection in front of the vehicle in the range of the radar. Make sure the radar aimer set is set aside away from the range of the radar until you are instructed to place it in front of the vehicle. If you are still getting an unwanted radar reflection, stack tires about 1.5 m (4.9 ft) in height in front of either the immovable object, such as a pole, or in front of any object causing the unwanted reflections. The tires will block the radar reflections. Make sure NO TARGET appears on the MID. If it still does not appear, move the vehicle to a different location until NO TARGET appears on the MID.

    4. Position the stand set to align the hole (E) of the stand set with the point (F). Then make sure that you can see the mark through the hole.

    NOTE:  When the stand set is placed, the MID will display "RADAR OK" with code 100.

    Courtesy of HONDA, U.S.A., INC.
    Courtesy of HONDA, U.S.A., INC.

    5. Set the reflector (A) of the stand set to position Y2, then select "Enter" on the HDS.

    Courtesy of HONDA, U.S.A., INC.

    6. Confirm that "The radar aiming has been completed" on the HDS and follow the screen prompts.

    NOTE:

    • The aiming failure code is not stored and cannot be read with the HDS, so note the code before turning the vehicle to the OFF (LOCK) mode.
    • The result of the horizontal radar aiming can be confirmed by the HDS or the MID.
    • When the target is out of range, the horizontal radar aiming is not complete. The MID will display "NO TARGET". If the aiming failure code 120, 122, 123, or 124 is indicated, the aiming conditions were not set-up correctly.
    • Inspect the millimeter wave radar mounting for bent or damaged parts.
    • If the MID indicates an aiming failure code, refer to the table below. Then repeat the vertical aiming procedure.
    • The aiming information obtained is stored in the millimeter wave radar.

    Aiming failure code (on the MID)  Cause  How to solve 
    120 Two or more aiming targets exist. Remove all reflective objects except the correct special tools, and repeat the aiming procedure.
    122 The distance of the aiming target is out of specification. Set the distance to the aiming target 3, 850-4, 150 mm (151.57-163.39 in), and repeat the aiming procedure.
    123 The aiming target is moved. Do the aiming procedure again.
    124 The angle of the millimeter wave radar is exceeding the adjustable range or the right and left position of the aiming target is out of the specified range. Inspect and adjust the millimeter wave radar mounting position or reset the aiming target at the correct position, and repeat the aiming procedure.

    7. Turn the vehicle to the OFF (LOCK) mode.

    8. Install the radar cover.
