Clutch System Description - Clutch Pedal Position Switch (M/T)

WARNING: This page is about a different variant/trim than selected.

Clutch pedal position switch A is installed on the clutch pedal.

Clutch pedal position switch A is mostly used to start up the engine by turning the vehicle to the ON mode or to restart the engine when recovering from an engine stall. This system works when the clutch is disengaged.
