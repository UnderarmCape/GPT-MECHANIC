DTC P0107, P0108 (K20C1) (2017 2018 2019)

DTC P0107:  Manifold Absolute Pressure (MAP) Sensor Circuit Low Voltage

DTC P0108:  Manifold Absolute Pressure (MAP) Sensor Circuit High Voltage

General Description 

Courtesy of HONDA, U.S.A., INC.

The manifold absolute pressure (MAP) sensor measures the pressure or vacuum in the manifold. This measurement is converted into an electrical signal which the powertrain control module (PCM) uses to monitor the engine. If the signal voltage from the MAP sensor is a set value for a specified time, the PCM detects a malfunction and stores a DTC.

Monitor Execution, Sequence, Duration, DTC Type 

Execution Continuous
Sequence None
Duration 0.5 second or more
DTC Type One drive cycle, MIL on

Enable Conditions 

Condition Minimum Maximum
Engine speed [Engine Speed] 100 rpm -

[ ]: HDS Parameter

Malfunction Threshold 

DTC: P0107 

The MAP sensor output voltage [MAP Sensor] is less than 0.118484 V for at least 0.5 second.

DTC: P0108 

The MAP sensor output voltage [MAP Sensor] is greater than 4.893112 V or more for at least 0.5 second.

Possible Cause 

NOTE:  The causes shown may not be a complete list of all potential problems, and it is possible that there may be other causes.

DTC: P0107 

  • MAP sensor PB line short to ground
  • MAP sensor VCC line open

DTC: P0108 

  • MAP sensor SG line open
  • MAP sensor VCC line short to ground
  • MAP sensor power supply line short to ground

Common 

  • MAP sensor failure
  • PCM internal circuit failure

Diagnosis Details 

Conditions for setting the DTC 

When a malfunction is detected, the MIL comes on and a Pending DTC, a Confirmed DTC, and the freeze data are stored in the PCM memory.

Conditions for clearing the DTC 

The MIL is cleared if the malfunction does not return in three consecutive trips in which the diagnostic runs. The MIL, the Pending DTC, the Confirmed DTC, and the freeze data can be cleared with the scan tool Clear command.
