Millimeter Wave Radar Removal and Installation (2/4-door) (2016 2017 2018): Installation

NOTE:  Before installing the front bumper, do the vertical radar aiming.

  1. Component of Millimeter Wave Radar - Install
    Courtesy of HONDA, U.S.A., INC.
    		 NOTE:  If you removed the components of the millimeter wave radar, install all removed parts.

    1. Install these items:

    • Spacer B
    • Grip (A)
    • Vertical radar aiming bolt (C)

    NOTE:  The grip and spacer B must be replaced as a new one.

    2. Install the millimeter wave radar (D) on the bracket (E).

    3. Install the screws (F).

    4. Measure the clearance 24.7 mm (0.972 in) between the millimeter wave radar and the bracket.

    • If the clearance is out of the standard, adjust the vertical aiming bolt.
  2. Millimeter Wave Radar Assembly - Install
    Courtesy of HONDA, U.S.A., INC.
    		 1. Install the millimeter wave radar assembly (A).

    2. Connect the connector (B).
  3. Millimeter Wave Radar - Vertical Radar Aim
    Courtesy of HONDA, U.S.A., INC.
    		 NOTE: 
    • The millimeter wave radar must be re-aimed if the millimeter wave radar is removed or replaced: the vertical radar aiming mechanically done using the level included in the alignment set.
    • When the millimeter wave radar is adjusted on a floor surface that has more than one degree of horizontal slope (drainage slope), the vertical radar aiming cannot be adjusted correctly. Check the levelness of the floor surface, but if there is a continuous slope, then adjust the angle of millimeter wave radar so it is parallel to the floor surface. Lay a ruler or other flat straight object on the floor surface and put the level on top to confirm the levelness of the floor surface.
    • Have the driver sit in the driver's seat.
    • Clean the surface of the millimeter wave radar.
    • The 3.5 mm hex socket driver used in this procedure is included in the adaptive speed control alignment tool SPX 10243 or adjuster, radar 3.5 mm 07AAA-TGVA100.

    1. Put the level on the pad of the millimeter wave radar.

    2. Turn the vertical radar aiming bolt (A) using the 3.5 mm hex socket driver (B), and adjust the angle of millimeter wave radar so that the air bubble in the level is centered.

    NOTE:  To correctly confirm the bubble position in the level, have a look from the side.

    3. Remove the level.
