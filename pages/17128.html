DTC B261C, B261D, B261E, B261F

DTC B261C  : Rear 1st Sensor Data Failure

DTC B261D  : Rear 2nd Sensor Data Failure

DTC B261E  : Rear 3rd Sensor Data Failure

DTC B261F  : Rear 4th Sensor Data Failure

NOTE: 

  • If you are troubleshooting multiple DTCs, be sure to follow the instructions in B-CAN System Diagnosis Test Mode A .
  • Before you troubleshoot, resetting the parking and back-up sensor control unit .
  • The connection order of the sensor is 1st -> 2nd -> 3rd -> 4th from the side near the control unit.

DTC (Parking and Back-Up Sensor Control Unit)

  1. Problem verification

    -1. Clear the DTCs with the HDS.

    -2. Turn the vehicle to the OFF (LOCK) mode and then the ON mode.

    -3. Wait for at least 6 seconds.

    -4. Check for DTCs with the HDS.

    DTC Description DTC
    B261C Rear 1st Sensor Data Failure  
    B261D Rear 2nd Sensor Data Failure  
    B261E Rear 3rd Sensor Data Failure  
    B261F Rear 4th Sensor Data Failure  

    Is DTC B261C, B261D, B261E, and/or B261F indicated?

    YES 

    Go to step 2.

    NO 

    Intermittent failure, the system is OK at this time. Check for loose or poor connections.

  2. DTC check

    -1. Check for DTCs with the HDS.

    DTC Description DTC
    B261C Rear 1st Sensor Data Failure  
    B261D Rear 2nd Sensor Data Failure  
    B261E Rear 3rd Sensor Data Failure  
    B261F Rear 4th Sensor Data Failure  
    B2647 Rear Sensor Power Failure  
    B2649 Rear Sensor Signal Short to Ground  

    Is DTC B261C, B261D, B261E, B261F, B2647, and/or B2649 indicated?

    YES: B261C, B261D, B261E, and B261F indicated

    Go to step 3.

    YES: B261D, B261E, and B261F indicated

    Go to step 4.

    YES: B261E and B261F indicated

    Go to step 5.

    YES: B261F indicated

    Go to step 6.

    YES: B2647 indicated

    Go to parking and back-up sensor system DTC B2647 troubleshooting .

    YES: B2649 indicated

    Go to parking and back-up sensor system DTC B2649 troubleshooting .

    NO 

    Intermittent failure, the system is OK at this time. Check for loose or poor connections.

  3. Open wire check (BOR SIDE L, SOR SIDE L, E2 SIDE L lines)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    Parking and back-up sensor control unit 16P connector
    Left rear corner sensor 6P connector

    -3. Check for continuity between test points 1 and 2 respectively.

    Test condition Vehicle OFF (LOCK) mode
    Parking and back-up sensor control unit 16P connector: disconnected
    Left rear corner sensor 6P connector: disconnected
    Test point 1 Parking and back-up sensor control unit 16P connector No. 16
    Test point 2 Left rear corner sensor 6P connector No. 6
    Test point 1 Parking and back-up sensor control unit 16P connector No. 14
    Test point 2 Left rear corner sensor 6P connector No. 4
    Test point 1 Parking and back-up sensor control unit 16P connector No. 12
    Test point 2 Left rear corner sensor 6P connector No. 2

    Is there 1.0 Ω or less?

    YES 

    Replace the left rear corner sensor .

    NO 

    Repair an open or high resistance in the wire.
