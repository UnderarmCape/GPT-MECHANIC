DTC C1653-14 (Type-R) (2017 2018 2019 2020 2021)

DTC C1653-14  : Right-Rear Acceleration Sensor Lower Limit Abnormality

NOTE: Before you troubleshoot, review the general troubleshooting information .

DTC Description DTC Freeze Frame
C1653-14 Right-Rear Acceleration Sensor Lower Limit Abnormality    

DTC (Adaptive Damper System)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    Clear DTCs

    -3. Turn the vehicle to the OFF (LOCK) mode, then to the ON mode.

    -4. Wait for 60 seconds or more.

    -5. Check for DTCs with the HDS.

    DTC Description DTC Freeze Frame
    C1653-14 Right-Rear Acceleration Sensor Lower Limit Abnormality    

    Is DTC C1653-14 indicated?

    YES 

    The failure is duplicated. Go to step 2.

    NO 

    Intermittent failure, the system is OK at this time. Refer to intermittent failures troubleshooting . If the freeze data/on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the freeze data/on-board snapshot.

  2. Left-rear acceleration sensor performance check

    -1. Check the parameter(s) below with the HDS.

    Signal Current conditions
    Values Unit
    Left Rear Acceleration Sensor Voltage    

    Is there about 0 V?

    YES 

    Go to step 3.

    NO 

    Go to step 5.

  3. Open wire check (ADS SVCC line)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    Adaptive damper control unit 24P connector
    Right-rear acceleration sensor 3P connector

    -3. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Adaptive damper control unit 24P connector: disconnected
      Right-rear acceleration sensor 3P connector: disconnected
    Test point 1 Adaptive damper control unit 24P connector No. 17
    Test point 2 Right-rear acceleration sensor 3P connector (female terminals) No. 3:
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    The ADS SVCC wire is not open. Go to step 4.

    NO 

    Repair an open in the wire between the adaptive damper control unit and the right-rear acceleration sensor.

  4. Shorted wire check (ADS SVCC line)

    -1. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Adaptive damper control unit 24P connector: disconnected
      Right-rear acceleration sensor 3P connector: disconnected
    Test point 1 Adaptive damper control unit 24P connector No. 17
    Test point 2 Body ground

    Is there continuity?

    YES 

    Repair a short to body ground in the wire between the adaptive damper control unit and the right-rear acceleration sensor.

    NO 

    The ADS SVCC wire is OK. Check for loose terminals and poor connections in the adaptive damper control unit 24P connector. Check for any authorized service information related to the DTCs or symptoms you are troubleshooting. If they are OK, replace the adaptive damper control unit .

  5. Right-rear acceleration sensor check

    -1. Check the right-rear acceleration sensor .

    Is the right-rear acceleration sensor OK?

    YES 

    Go to step 6.

    NO 

    Replace the right-rear acceleration sensor .

  6. Open wire check (ADS FR L G line)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    Adaptive damper control unit 24P connector
    Right-rear acceleration sensor 3P connector

    -3. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Adaptive damper control unit 24P connector: disconnected
      Right-rear acceleration sensor 3P connector: disconnected
    Test point 1 Adaptive damper control unit 24P connector No. 22
    Test point 2 Right-rear acceleration sensor 3P connector (female terminals) No. 1:
    Courtesy of HONDA, U.S.A., INC.

    Is there continuity?

    YES 

    The ADS FR L G wire is not open. Go to step 7.

    NO 

    Repair an open in the wire between the adaptive damper control unit and the right-rear acceleration sensor.

  7. Shorted wire check (ADS FR L G line)

    -1. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      Adaptive damper control unit 24P connector: disconnected
      Right-rear acceleration sensor 3P connector: disconnected
    Test point 1 Adaptive damper control unit 24P connector No. 22
    Test point 2 Body ground

    Is there continuity?

    YES 

    Repair a short to body ground in the wire between the adaptive damper control unit and the right-rear acceleration sensor.

    NO 

    The ADS FR L G wire is OK. Check for loose terminals and poor connections in the adaptive damper control unit 24P connector. Check for any authorized service information related to the DTCs or symptoms you are troubleshooting. If they are OK, replace the adaptive damper control unit .
