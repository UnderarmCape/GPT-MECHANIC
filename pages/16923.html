DTC U0029-00 (EPS Control Unit, With LKAS)

DTC U0029-00  : F-CAN Malfunction (Bus-Off)

NOTE: 

  • Before you troubleshoot, review the general troubleshooting information .
  • Troubleshoot any PGM-FI system DTCs first .
  • This DTC is stored by communication failure between the F-CAN line and the EPS control unit. When DTC U0029-00 is indicated, the F-CAN line has already returned to normal. Check for loose terminals and poor connections at the connectors. If the connectors are OK, clear the DTC and following this troubleshooting.
DTC Description DTC Freeze Frame
U0029-00 F-CAN Malfunction (Bus-Off)    

DTC (EPS)

  1. Problem verification

    -1. Turn the vehicle to the ON mode.

    -2. Clear the DTC with the HDS.

    Clear DTCs

    -3. Turn the vehicle to the OFF (LOCK) mode, then to the ON mode.

    -4. Check for DTCs with the HDS.

    DTC Description DTC Freeze Frame
    U0029 F-CAN Malfunction (Bus-Off)    

    Is DTC U0029-00 indicated?

    YES 

    The failure is duplicated. Go to step 2.

    NO 

    Intermittent failure, the system is OK at this time. Refer to intermittent failures troubleshooting . If the freeze data/on-board snapshot of this DTC is recorded, try to reproduce the failure under the same conditions with the freeze data/on-board snapshot.

  2. CAN gateway system DTC check

    -1. Check for CAN gateway system DTCs with the HDS.

    DTC Description DTC
       

    Are any DTCs indicated?

    YES 

    Go to the troubleshooting for CAN gateway system DTC(s) .

    NO 

    Go to step 3

  3. F-CAN circuit communication check

    -1. Select the FUNCTION TEST in the CAN gateway with the HDS, then select the F-CAN Bus Connected Unit Check.

    F-CAN Bus Connected Unit Check

    Does the CAN gateway detect the EPS control unit Bus channels B?

    '16-18 2/4-door: EPS control unit is Not Available for Bus B

    Go to step 4.

    '19-21 2/4-door: EPS control unit is Not Available for Bus B

    Go to step 5.

    '17-19 5-door: EPS control unit is Not Available for Bus B

    Go to step 4.

    '20-21 5-door: EPS control unit is Not Available for Bus B

    Go to step 5.

    EPS control unit is Available for Bus B

    Check for loose terminals and poor connections in the EPS control unit connectors. Check for any authorized service information related to the DTCs or symptoms you are troubleshooting. If they are OK, replace the EPS motor/control unit .

  4. Open wire check (F-CAN B_H, F-CAN B_L lines)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    EPS control unit connector B (6P)
    CAN gateway 12P connector

    -3. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      EPS control unit connector B (6P): disconnected
      CAN gateway 12P connector: disconnected
    Test point 1 EPS control unit connector B (6P) No. 3
    Test point 2 CAN gateway 12P connector (female terminals) No. 12:
    Test point 1 EPS control unit connector B (6P) No. 1
    Test point 2 CAN gateway 12P connector (female terminals) No. 5:
    Courtesy of HONDA, U.S.A., INC.

    Is there 1.0 Ω or less?

    YES 

    The F-CAN B_H and F-CAN B_L wires are OK. Check for poor connections or loose terminals at the CAN gateway and the EPS control unit connector. Check for any authorized service information related to the DTCs or symptoms you are troubleshooting. If they are OK, replace the EPS motor/control unit .

    NO 

    Repair an open in the wire between the CAN gateway and the EPS motor/control unit.

  5. Open wire check (F-CAN B_H, F-CAN B_L lines)

    -1. Turn the vehicle to the OFF (LOCK) mode.

    -2. Disconnect the following connectors.

    EPS control unit connector B (6P)
    CAN gateway 16P connector

    -3. Check for continuity between test points 1 and 2.

    Test condition Vehicle OFF (LOCK) mode
      EPS control unit connector B (6P): disconnected
      CAN gateway 16P connector: disconnected
    Test point 1 EPS control unit connector B (6P) No. 3
    Test point 2 CAN gateway 16P connector (female terminals) No. 6:
    Test point 1 EPS control unit connector B (6P) No. 1
    Test point 2 CAN gateway 16P connector (female terminals) No. 14:
    Courtesy of HONDA, U.S.A., INC.

    Is there 1.0 Ω or less?

    YES 

    The F-CAN B_H and F-CAN B_L wires are OK. Check for loose terminals and poor connections in the EPS control unit connectors. Check for any authorized service information related to the DTCs or symptoms you are troubleshooting. If they are OK, replace the EPS motor/control unit .

    NO 

    Repair an open in the wire between the EPS control unit and the CAN gateway.
