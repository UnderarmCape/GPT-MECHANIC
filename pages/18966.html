UPDATING SOFTWARE IN THE ROBINAIR R-1234YF A/C RECOVER, RECYCLE, RECHARGE MACHINE

UPDATING SOFTWARE IN THE ROBINAIR R-1234YF A/C RECOVER, RECYCLE, RECHARGE MACHINE

TECHNICAL SERVICE BULLETIN

Reference Number(s): JA1289, Date of Issue:  May 01, 2021
HONDA: All Models
Superceded Bulletin(s): JA1289 Version 2, Date of Issue:  March 01, 2020
NOTE: Supersedes version 2, dated March 2020. See REVISION SUMMARY

AFFECTED VEHICLES

All models using R-1234yf refrigerant

REVISION SUMMARY

The images in this job aid have been updated to reflect the current software version; American Honda recommends you read this entire job aid.

BACKGROUND

This job aid shows you how to update the software in the Robinair R-1234yf Recover, Recycle, Recharge Machine (Model No. ROB421234).

CHECKING/ENTERING DEALER INFORMATION

  1. Press MENU.
  2. Press 1  to select Unit Setup. 
  3. Press 5  to select Dealer Info. 
  4. Press 1  to select Manual Entry. 
  5. Use the arrow keys and keypad to enter or correct your dealer information.

WI-FI CONNECTION SETUP

NOTE: If the machine is already connected to Wi-Fi, go to SOFTWARE UPDATE INSTALLATION .
  1. Press MENU.
  2. Press 1  to select Unit Setup. 
  3. Press the right arrow twice, then press 6  to select Wifi Configuration. 
  4. Press 1  or 2  depending on your Wi-Fi network setup.
  5. Follow the remaining screen prompts to complete the Wi-Fi configuration.

SOFTWARE UPDATE INSTALLATION

  1. Insert an SD card into the A/C machine.
    NOTE: An SD card was included with the machine when delivered. If the SD card is missing, insert a blank SD, SDHC, or SDXC card between 32 MB and 16 GB capacity (minium class 4) formatted to FAT or FAT32.
  2. Make sure the Wi-Fi is connected.
  3. Reboot the machine.
  4. The machine will prompt a firmware update; press OK. 
    NOTE: If the machine does not prompt a firmware update, the machine is not connected to the Internet. Check the Wi-Fi connection again.

    The machine will search for the new updates; this can take several minutes.
  5. When the machine shows New version available  , select OK  .

    The machine will start downloading the new software to the SD card.

    NOTE: The download can take several minutes depending on internet speed.

    When the download is complete, the machine will show the download was successful.
  6. Reboot the machine.
    NOTE: Do not  remove the SD card from the machine.
  7. When the following screen appears, press 1  to select INSTALL. 
  8. When the Start Installation!  screen appears, press OK. 

    The installation will start.
  9. When the installation is complete, press ESC. 

    The new application will start loading.
  10. Once the application launches, make sure the software version listed under the Honda logo lists the Robinair R-1234yf A/C Recover, Recycle, Recharge Machine software version shown on the iN.
    NOTE:
    • To check for the latest software version, from the iN home page, go to SERVICE  > Service Bay  > Diagnostic Tools Software Versions. 
    • Always make sure you have the latest software version. If not, update it.

    END
